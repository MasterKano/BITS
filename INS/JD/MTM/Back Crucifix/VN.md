
# GLOBAL VN SCHEMA (Applies to All Volumes)

## Purpose
Standardize all Viewing Notes into an operator-friendly format:
- **Less prose** (decisionable cues)
- **Explicit gates** (what must be true)
- **Quality checks** (how you verify it)
- **Fast drills** (how you install it)

---

## Numbering (Single-Document)
- Volume header: `N.0`
- Chapter section: `N.1`, `N.2`, `N.3` (match the instructional’s sub-chapter titles)
- Optional sub-points: `N.1.1`, `N.1.2` (only if operationally necessary)
- End-of-volume standards:
  - `N.90 Volume N Final Operator Checklist`
  - `N.95 Volume N Micro-Drill`

---

## Standard Unit Schema (Use for Every Chapter Section)

### Objective
- What capability the student must acquire by the end of the section.
- Written as a measurable outcome (not a theme).

### Primary decision rule
- The single most important “if X, then Y” rule that governs this section.

### Decision gates (explicit)
- A short list of **must-be-true conditions**.
- Format: `G# Name: condition -> required action`.
- Gates should be binary whenever possible (pass/fail), not descriptive.

### Quality checks (operator)
- How you verify gates are satisfied in live training.
- Format as observable checks:
  - “Can partner do X?”
  - “Can you hold Y for Z seconds?”
  - “Can you name/locate A/B/C immediately?”

### Common errors / failure signatures
- Predictable failure modes and how they show up.
- Should read like troubleshooting signals.

### Operator cues (short)
- 3–6 short phrases the coach can say in sparring.
- No explanation. Command language only.

---

## Master Decision Tree (Volume-Level)
Each volume should include a volume-level decision tree when it materially improves execution.
- Structure:
  - “What state am I in?”
  - “What’s failing?”
  - “Which module do I run next?”
- Keep it short; chapter-level gates remain the primary control.

---

## Final Operator Checklist (End of Volume)
- 6–12 bullets maximum.
- Each bullet should map directly to a chapter gate or quality check.
- Should be usable as a “go/no-go” audit.

---

## Micro-Drill Template (End of Volume)
Every volume ends with at least one short drill to install the volume’s main skill.

**Micro-Drill — [Name] ([Duration])**
- **Start:** exact start position/state.
- **Objective:** one measurable outcome.
- **Constraints:** what is disallowed / what partner is allowed to do.
- **Win condition:** measurable success criteria.
- **Rounds:** suggested rounds/reps with timing.

---

## Operator Language Rules (Style Constraints)
- Default to verbs and binary checks.
- Prefer: “If/then”, “must”, “fail”, “rebuild”, “hold”.
- Avoid: long rationale, motivational language, narrative.
- If uncertain, add a gate rather than extra prose.

## 1.1 Intro (0:00–2:48)

### Objective
- Establish why back crucifix is strategically high value despite scoring no points.
- Install the system’s headline advantages: angle change, defense removal, dilemma creation, accessibility.

### Primary decision rule
- Select back crucifix when your priority is **control-to-finish reliability** (not points), especially when you can (a) remove hands as defense, and (b) create a strangle↔armlock dilemma.

### Decision gates (explicit)
- **G1 Value:** no-points does not downgrade the position if control + finishing leverage are high.
- **G2 Angle:** if you can create a strong angle shift (more perpendicular), strangle access improves.
- **G3 Defense removal:** if arms are controlled, hands cannot act as first-line strangle defense.
- **G4 Dilemma:** if you can switch strangles ↔ armlocks without relocating your body, you can force predictable reactions.
- **G5 Body-type:** if conventional back triangles/body triangles are unreliable (e.g., shorter legs), crucifix is a strong substitute.

### Quality checks (operator)
- You can justify crucifix choice in one sentence using: **Value / Angle / Defense removal / Dilemma / Body-type**.
- You can name the intended finish family (strangle vs armlock) without changing the control objective.

### Common errors / failure signatures
- Treating crucifix as “low value” because it doesn’t score.
- Importing rear-mount habits (torso/hip-first priorities) into an arm-centric control system.
- Switching finish families by big body movement rather than tight reconfiguration.

### Operator cues (short)
- “Points irrelevant: control + finish.”
- “Angle + hands removed.”
- “Dilemma: strangle ↔ armlock.”

## 1.2 Building Your Understanding of the Back Crucifix From the Ground Up - The Logic of Back Control in Jiu Jitsu - The Standard Method of Back Control (2:48–10:58)

### Objective
- Define the baseline model of standard back control so crucifix differences are measurable and coachable.

### Primary decision rule
- If you are **not behind the elbows**, you do **not** have back control (even with chest-to-back contact).

### Decision gates (explicit)
- **G1 Ideal model:** opponent’s upper body between your elbows + hips between your knees.
- **G2 Minimum model:** at minimum, torso is meaningfully controlled between your elbows (upper-body gate).
- **G3 Boundary condition:** “behind the elbows” is the defining back-control boundary.
- **G4 Escape condition:** if opponent is neither meaningfully between elbows nor knees → treat as loss of back control.

### Quality checks (operator)
- You can classify instantly: **Ideal / Degraded / Minimal / None**.
- When degraded, you can state the rebuild priority: “restore upper-body between elbows.”

### Common errors / failure signatures
- “Turtle chest contact = back control” (fails the behind-elbows boundary).
- Chasing perfect lower-body control while losing the upper-body gate.
- Not recognizing the escape condition and continuing to act as if you still have the back.

### Operator cues (short)
- “Behind elbows = back control.”
- “Upper body between elbows = alive.”
- “Neither = escape.”

## 1.3 Crucifix Back Control is Very Different (10:58–17:48)

### Objective
- Define crucifix-specific priorities so students stop using conventional back-control assumptions.
- Install a hard end-of-control signal for crucifix.

### Primary decision rule
- In crucifix: prioritize **arm-control locus + chest-to-back connection** over classic spine-to-spine alignment and hip-between-knees logic.

### Decision gates (explicit)
- **G1 Commonality:** some chest-to-back contact persists (shared requirement across both).
- **G2 Hard fail (contact loss):** if chest-to-back contact is fully lost and opponent slides away → recover contact or switch systems.
- **G3 Control-locus shift:**
  - standard back control: hips/torso control emphasis (hips between knees)
  - back crucifix: arm/elbow control emphasis (elbow between knees)
- **G4 Alignment tolerance:** crucifix alignment varies (perpendicular ↔ more aligned); do not demand spine-to-spine.
- **G5 Defense mismatch:** expect rear-mount defenses to appear; exploit the mismatch (they often don’t map).

### Quality checks (operator)
- You can answer “What are we controlling?” with: **arms/elbow line first**.
- You run the contact check continuously: “chest-to-back present: yes/no.”
- You do not chase alignment aesthetics at the expense of arm control.

### Common errors / failure signatures
- Over-prioritizing spine alignment and losing arm control.
- Late recognition of contact loss (waiting until opponent slides out).
- Treating conventional rear-mount defense logic as optimal vs crucifix.

### Operator cues (short)
- “Elbow between knees.”
- “Contact check: chest-to-back?”
- “If contact lost: recover or switch.”

## 2.1 Controlling the Back Crucifix Position - Finding the Focal Points of Control - First Focal Point: The Far Arm (0:00–21:27)

### Objective
- Identify crucifix control focal points and install **far arm** as the first focal point you must own.

### Primary decision rule
- If far arm is not **functionally immobilized**, you are not allowed to advance (finish, switch systems, or “relax”). Rebuild far arm first.

### Decision gates (explicit)
- **G1 Focal-point gate:** treat **far arm** as the first control focal point (this volume’s priority).
- **G2 Immobilization gate:** far arm must be *functionally* immobilized (not merely “held”).
- **G3 Stability gate:** opponent cannot create a clean elbow-extraction pathway without you immediately re-locking control.

### Quality checks (operator)
- Partner attempts to extract elbow/arm line: you can stop it **immediately** and re-establish control.
- You can hold far-arm immobilization for **10 seconds** against active “limp-out” attempts.
- You can state (out loud) what you’re doing: “I’m in far-arm control; I’m preventing elbow escape.”

### Common errors / failure signatures
- Treating far arm as “good enough” and advancing early → slow leak → arm comes free.
- Fixing secondary concerns (alignment, finishing grips) while the far arm is still mobile.
- Not diagnosing which mechanical element failed (hook vs wedge vs prop) → repeating the same leak.

### Operator cues (short)
- “Far arm first.”
- “Immobilize before attack.”
- “Stop the limp-out.”
- “Rebuild—don’t chase.”

## 2.2 The Key Mechanical Principle of Back Crucifix Arm Control: Wedge, Hook, and Prop Principle (21:27–28:14)

### Objective
- Reduce far-arm control to a binary completeness test: **Hook + Wedge + Prop**.

### Primary decision rule
- If you do not have **Hook + Wedge + Prop** simultaneously, assume the elbow will eventually slip free; immediately replace the missing element.

### Decision gates (explicit)
- **G1 Hook gate:** your leg provides a **hook** that captures the forearm/arm line.
- **G2 Wedge gate:** your **knee wedge** blocks the elbow from “limping out.”
- **G3 Prop gate:** at least one **foot on the mat** (adjustment + power). No prop = eventual escape.
- **G4 Completeness gate:** you must be able to point to all three at once (“this is hook / wedge / prop”).
- **G5 Orientation-response gate:** if opponent changes arm orientation, you adjust while keeping all three elements present.

### Quality checks (operator)
- “3-point audit” passes instantly:
  - You can physically indicate hook, wedge, prop without repositioning.
- If partner rotates/turns their arm line: you can maintain completeness without losing control.
- If your feet leave the floor: treat it as a **red flag** and restore prop immediately.

### Common errors / failure signatures
- Hook without wedge → elbow limps out.
- Wedge + hook without prop → you can’t adjust; control degrades over time.
- Over-locking in a way that kills the wedge effect (control feels “tight” but becomes leak-prone).
- Ignoring orientation changes → gradual loss → elbow escapes.

### Operator cues (short)
- “Hook. Wedge. Prop.”
- “Foot on the mat.”
- “Knee wedges the elbow.”
- “If it leaks, one element is missing.”

## 3.1 The Second Focal Point: The Near Shoulder (0:00–12:49)

### Objective
- Install **Near Shoulder** as the second mandatory control dial that stabilizes the crucifix and prevents turn-in/sit-up chains.

### Primary decision rule
- If the near shoulder is mobile, assume escapes will chain. Rebuild near-shoulder control before chasing finishes.

### Decision gates (explicit)
- **G1 Two-dial gate:** crucifix control requires both **far arm** (V2) and **near shoulder** (V3).
- **G2 Mobility gate:** near shoulder must be *functionally pinned/managed* (not merely “touched”).
- **G3 Turn-in prevention gate:** near shoulder control must deny the opponent’s ability to rotate into you as the default escape route.

### Quality checks (operator)
- Opponent cannot freely rotate shoulders to face you.
- You can hold near-shoulder management for **10 seconds** against active turning attempts *without* sacrificing far-arm control.
- You can state which dial is failing: “Far arm leak” vs “Near shoulder leak.”

### Common errors / failure signatures
- Over-fixating on far arm and ignoring the shoulder line → opponent turns in or sits up.
- “Winning the arm” but losing the shoulder—control collapses into scrambles.
- Trying to finish while the shoulder line is still rotating.

### Operator cues (short)
- “Second dial: shoulder.”
- “Stop the turn.”
- “Pin the shoulder line.”
- “If they rotate, rebuild.”

## 3.2 The Three by Six Crucifix Positional Theory (12:49–31:49)

### Objective
- Provide an organizing map (“Three by Six”) to structure maintenance, upgrades, and decision-making under resistance.

### Primary decision rule
- When control is stable, use the 3×6 model to choose the next upgrade; when control is unstable, use it to diagnose which structural category is failing.

### Decision gates (explicit)
- **G1 Organization gate:** you must be able to locate your current configuration inside the 3×6 map (no “free-floating” crucifix).
- **G2 Upgrade gate:** upgrades must preserve both focal points (far arm + near shoulder).
- **G3 Troubleshoot gate:** when something fails, identify the failing category first; do not guess techniques.

### Quality checks (operator)
- You can verbally label where you are in the map (“I’m in X category; upgrading to Y”).
- During upgrades, opponent cannot create immediate arm-sit/turn-in/stand-up momentum.
- If you lose position, you can name the failure category within 2 seconds.

### Common errors / failure signatures
- Treating 3×6 as theory-only and not using it for live selection.
- Upgrading by moving body/legs in a way that breaks one focal point.
- “Technique hunting” instead of category diagnosis.

### Operator cues (short)
- “Name the box.”
- “Upgrade without leaks.”
- “Which category failed?”

## 3.3 How to Stay Away From and Recover From the Seated Arm Sit (31:49–47:24)

### Objective
- Prevent the arm-sit from forming; if it forms, recover without losing the system.

### Primary decision rule
- Treat arm-sit as an early-warning escape: intervene early; if late, recover immediately—do not continue normal offense.

### Decision gates (explicit)
- **G1 Early-warning gate:** once sit-up mechanics start, prioritize prevention over finishing.
- **G2 Recovery gate:** if arm-sit is achieved, switch to recovery mode until both focal points are re-owned.
- **G3 Loop gate:** after prevention/recovery, re-check far arm + near shoulder before advancing.

### Quality checks (operator)
- You can stop arm-sit attempts **before** the opponent fully stabilizes seated posture.
- From a late stage, you can recover to a stable crucifix state within **30 seconds**.
- You can return to 3×6 labeling immediately after recovery.

### Common errors / failure signatures
- Ignoring early arm-sit signals and continuing to hunt a finish.
- Recovering far arm but leaving near shoulder loose (arm-sit repeats).
- Over-committing hands/position during the recovery and getting turned.

### Operator cues (short)
- “Arm-sit—early.”
- “Prevent first, recover fast.”
- “Re-own both dials.”

## 3.4 Breaking Locked Hands (47:24–53:10)

### Objective
- Open locked-hand defenses without donating the escape.

### Primary decision rule
- Do not sacrifice focal points to break the lock; break the lock *from stable control*.

### Decision gates (explicit)
- **G1 Control-first gate:** lock-breaking attempts must preserve far arm + near shoulder.
- **G2 Post-break gate:** once hands open, immediately route to finish selection or re-stabilize (no pause).
- **G3 Re-lock gate:** if hands re-lock, re-run the protocol; don’t escalate sloppily.

### Quality checks (operator)
- You can open the lock without losing the arm-control structure.
- After opening, you can transition to a finish pathway within **2–3 seconds**.
- Partner cannot repeatedly re-lock without you resetting position.

### Common errors / failure signatures
- Breaking the lock by loosening control → opponent escapes instead of opening.
- Opening the lock but hesitating (hands re-lock).
- Tunnel-vision on hands instead of maintaining focal points.

### Operator cues (short)
- “Control first.”
- “Open → finish.”
- “No donation.”

---

## 3.5 The Relationship Between Rear Mount and Back Crucifix (53:10–56:37)

### Objective
- Define when to transition between rear mount and crucifix based on control certainty and opponent reactions.

### Primary decision rule
- Switch systems only when the transition **increases control certainty** or denies a known escape sequence.

### Decision gates (explicit)
- **G1 Certainty gate:** choose the system where you can maintain the control dials most reliably.
- **G2 Reaction gate:** if opponent’s defense suits rear mount but fails against crucifix (or vice versa), switch.
- **G3 Re-check gate:** after any transition, immediately re-establish the new system’s key controls before attacking.

### Quality checks (operator)
- You can transition without a scramble (dominant control persists).
- After transition, you can state the new primary controls (rear mount vs crucifix) and hold for **10 seconds**.

### Common errors / failure signatures
- Switching because it’s “available” rather than because it upgrades certainty.
- Transitioning while a focal point is already failing (compounds failure).
- Treating rear mount priorities as identical to crucifix priorities.

### Operator cues (short)
- “Choose certainty.”
- “Switch to deny escapes.”
- “Transition then stabilize.”

---

## 3.6 The Relationship Between Crucifix and T Kimura (56:37–1:03:37)

### Objective
- Define the crucifix↔T-kimura interface as an upgrade path when it improves control/finish access.

### Primary decision rule
- Take the T-kimura interface only if it preserves (or improves) crucifix control integrity; otherwise, stay and rebuild.

### Decision gates (explicit)
- **G1 Integrity gate:** interface must not free the far arm or loosen the near shoulder line.
- **G2 Finish-access gate:** interface should create a clearer finishing pathway than staying in crucifix.
- **G3 Abort gate:** if the interface attempt creates a leak, abort and return to crucifix fundamentals.

### Quality checks (operator)
- You can attempt the interface without giving the opponent a turn-in or sit-up pathway.
- If opponent resists, you can return to stable crucifix within **5 seconds**.

### Common errors / failure signatures
- Forcing the interface when it degrades control.
- “Chasing a submission” while focal points are failing.
- Not having a clean abort path (staying committed too long).

### Operator cues (short)
- “Interface only if it upgrades.”
- “If it leaks—abort.”
- “Control > submission.”

## 3.7 How to Control an Opponent Who Rises and Stands (1:03:37–1:10:24)

### Objective
- Maintain crucifix control through the standing phase by preserving focal points under changing leverage.

### Primary decision rule
- Standing changes leverage, not priorities: preserve far arm + near shoulder first; only finish once stability returns.

### Decision gates (explicit)
- **G1 Leverage-change gate:** expect instability spikes when they stand; tighten focal points before attacking.
- **G2 Anti-turn gate:** prevent turn-in while they rise (standing often amplifies turn-in attempts).
- **G3 Reset gate:** if control quality drops below threshold, re-seat structure before finishing.

### Quality checks (operator)
- You can keep the far arm trapped during the stand-up attempt.
- You can prevent immediate turn-in while standing.
- You can re-stabilize into a controllable configuration within **10–15 seconds** of them standing.

### Common errors / failure signatures
- Attacking during the leverage transition and losing the arm.
- Letting the opponent turn-in during the stand.
- Refusing to reset/re-seat control (trying to “finish anyway”).

### Operator cues (short)
- “Standing—stabilize first.”
- “Keep the arm.”
- “Stop the turn.”
- “Reset, then finish.”
