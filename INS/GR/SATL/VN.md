

# VIEWING NOTES – Systematically Attacking the Legs (Gordon Ryan)

## 1.0 Volume 1

### 1.1 Intro To Leg Locks
- Key concepts
  - Leglock skill gap: historically under-trained, producing weaker lower-body offense/defense relative to upper-body submissions.
  - System premise: create asymmetry in leg positions; avoid exchanges where both sides have equal access unless you deliberately choose a knowledge/mechanics shootout.
  - 50-50 is framed as a common symmetrical position; the preferred model is to work from entanglements where the opponent’s counter-access is structurally limited.
- Position–structure
  - Asymmetry is the governing lens for selecting entanglements and sequencing attacks.
- Key cues
  - Treat “mutual access” positions as riskier by default; bias toward platforms where your attacks are available while theirs are constrained.
- System tags
  - leglocks, asymmetry, positional-advantage, symmetry-risk

### 1.2 Overview
- Key concepts
  - Learning goal is systemic: understand hubs (entanglements) and how they connect; do not treat leglocks as isolated finishes.
  - Roadmap references core hubs: irimi ashi, outside ashi, cross ashi, inside ashi, 50-50, mutual ashi.
- Position–structure
  - Hubs are platforms that change exposure geometry, opponent counter-access, and the finishing lines available.
- Key cues
  - Learn (1) platform control requirements, then (2) exposure mechanisms, then (3) transition rules when exposure is denied.
- System tags
  - hub-chain, platform-logic, transitions

### 1.3 Theory
- Key concepts
  - Symmetry problem: 50-50 is inherently symmetrical; advantage comes from superior knowledge/mechanics rather than structure.
  - Preferred approach is moving away from symmetry into advantage platforms.
- Position–structure
  - “Asymmetry” limits opponent offense; “symmetry” permits mutual offense.
- Key cues
  - Prefer asymmetric hubs when possible; if you choose symmetric hubs, treat them as deliberate shootouts you intend to win by structure + mechanics.
- System tags
  - symmetry-vs-asymmetry, 50-50

### 1.4 Importance Of Inside And Outside Heelhooks
- Key concepts
  - Finishing credibility must exist from both inside and outside heel hook alignments; if you only finish one reliably, opponents adapt and take freedoms.
  - Threat credibility changes the whole exchange: real catastrophic break potential constrains opponent behavior.
- Position–structure
  - Inside vs outside heel hook are distinct finishing configurations requiring competence in both.
- Key cues
  - Build “real break” capability across both alignments so opponent can’t route their defense into your weak finishing side.
- System tags
  - heelhooks, threat-credibility, inside-heelhook, outside-heelhook

### 1.5 Battle Of Inside Positions
- Key concepts
  - Inside position is the primary battle: feet/knees inside opponent’s feet/knees governs who can initiate attacks safely.
  - Losing inside position implies you must pummel/reclaim lanes before expecting reliable offense.
- Position–structure
  - Inside dominance acts as an attack-permission gate; mixed lanes increase mutuality and risk.
- Key cues
  - Prioritize lane recovery (pummeling) before reaching for finishes from structurally losing lanes.
- System tags
  - inside-position, lane-control, pummeling, permission-gate

### 1.6 Irimi And Outside Ashi Garami Strategy
- Key concepts
  - Irimi and outside ashi are paired tools: use irimi to safely expose; use outside ashi to finish hard when alignment is established.
  - Irimi advantages: stronger control/stability and reduced vulnerability windows (as framed); assists exposure reliability and limits certain defensive freedoms.
  - Outside ashi advantages: stronger breaking alignment once exposure is secured; can convert exposure into catastrophic finishes.
- Position–structure
  - Irimi uses inside leg placement as a control layer that stabilizes exposure and limits disengagement/heel-slip tendencies.
- Key cues
  - Treat inside leg structure as an active control layer (anti-slip/anti-disengagement), not passive positioning.
- System tags
  - irimi-ashi, outside-ashi, hub-selection, exposure-stability

### 1.7 Cross And Inside Ashi Garami Strategy
- Key concepts
  - Cross ashi is valuable because it can control both legs (two-leg control advantage), increasing constraint and stabilizing exposure.
  - Cross ashi is linked to upgrade tools (leg laces / passing-the-leg concepts) that solve instability when one-leg control is insufficient.
- Position–structure
  - Two-leg control reduces opponent’s ability to rotate/withdraw freely and supports more stable exposure creation.
- Key cues
  - If one-leg control is unstable, prioritize structures that give access to the second leg and increase constraint before insisting on the finish.
- System tags
  - cross-ashi, two-leg-control, stability-upgrade

### 1.8 50/50 Strategy
- Key concepts
  - 50-50 is symmetrical; default approach is cautious because both sides have meaningful access.
  - Strategic risk increases against strong leglockers; preference remains to create asymmetry when possible.
  - Knee/leg alignment details act as a gate: correct defensive alignment reduces “easy wins.”
- Position–structure
  - 50-50 is a distinct hub with symmetry-driven constraints and positional gates.
- Key cues
  - Win structural details first (knee/leg alignment and access control) before expecting clean exposure.
- System tags
  - 50-50, symmetry, positional-gates, risk-management

### 1.9 Mutual Ashi Garami Strategy
- Key concepts
  - Mutual ashi is a shootout position and is generally avoided as a primary plan.
  - Timing/initiative rule: going second is framed as safer; initiating first often creates openings the opponent exploits.
- Position–structure
  - High mutual access hub where initiative selection becomes decisive.
- Key cues
  - Bias toward reactions that force partner commitment first, then counter into your exposure/finish line.
- System tags
  - mutual-ashi, shootout, initiative-rule, timing

### 1.10 General Escape Directions
- Key concepts
  - Escape direction families are predictable: withdrawal/extraction, pressure-forward, rotation/roll, and repummeling into counter-access.
  - Counter-leglock risk is emphasized: chasing exposure without control can turn into mutual danger.
  - Forward pressure (e.g., coming forward/knee-to-floor style compression) changes geometry and demands specific control responses.
- Position–structure
  - Correct control/transition choice depends on recognizing the defender’s chosen direction (withdraw vs rotate vs pressure vs repummel).
- Key cues
  - Use escape-direction recognition to select the right response; don’t persist on a line that the defender’s direction is already solving.
- System tags
  - escapes, defensive-directions, counter-risk, forward-pressure

### 1.11 Double Trouble
- Key concepts
  - “Double trouble” = controlling two of opponent’s legs; framed as categorically stronger than controlling only one.
  - Two-leg control prevents common disengagement patterns and limits rotational freedom used for escapes and counter-attacks.
- Position–structure
  - Control configuration (not a finish) that increases constraint and improves downstream exposure reliability.
- Key cues
  - When opponent escapes via straight withdrawal or rotation, upgrade toward two-leg control rather than chasing with one-leg control.
- System tags
  - double-trouble, two-leg-control, control-upgrade

### 1.12 Following A Leg
- Key concepts
  - Continuity principle: as the partner moves/rolls to clear exposure, you track the leg and emerge with control intact.
  - Goal is to preserve connection through motion so exposure can be recreated/stabilized after the movement resolves.
- Position–structure
  - Following preserves the platform across rotations; prevents the defender from resetting to neutral.
- Key cues
  - Don’t release and re-grip late during the roll; maintain attachment through the movement.
- System tags
  - follow-the-leg, continuity, roll-following

### 1.13 Switching Legs
- Key concepts
  - Switching legs is a decision tool: when primary access is denied/cleared, switch to the other leg rather than insisting into a stall.
  - Switching is framed as continuation of the chain, not a reset.
- Position–structure
  - Target replacement keeps advantage when defensive motion removes the primary line.
- Key cues
  - Don’t stay married to one heel; switch targets promptly when the defense has solved the primary line.
- System tags
  - switching-legs, target-selection, anti-stall

### 1.14 Basic Drills
- Drill notes (transcript-derived, best-effort clustering)
  - Drill theme: build reliable platform entries and transitions under movement; emphasize hip movement + structural leg placement (tightness/connection) rather than loose “throwing legs.”
  - Drill theme: install switching/transitions between hubs as a repeatable skill (rather than one-off reactions).
- Key cues
  - Platform first (control layer), then exposure; don’t chase finish mechanics from loose entries.
- System tags
  - drilling, platform-entries, hub-transitions, connection

### 1.15 Achilles Lock Drill
- Key concepts
  - Emphasis on using hip action and tight connection to create pressure rather than relying on arm strength alone.
  - Switching legs is referenced as part of continuity when the partner’s extraction develops.
- Drill notes (transcript-derived, best-effort clustering)
  - Repetition pattern: establish the line → apply pressure with tight connection → as partner pulls/extracts, maintain control or switch targets promptly.
- Key cues
  - Drive pressure off structure and connection; keep tightness as the partner moves.
- System tags
  - achilles-lock, drilling, hip-structure, switching-legs

### 1.16 Cowboy Drill
- Key concepts
  - Presented as a repeatable positioning/angle method that improves exposure/finish reliability.
  - Framed as broadly applicable in heel-hook contexts (positioning tool that supports downstream finishing).
- Drill notes (transcript-derived, best-effort clustering)
  - Use the cowboy motion to arrive at correct alignment, then proceed into exposure/finish mechanics.
- Key cues
  - Treat as an alignment tool that makes exposure durable and repeatable.
- System tags
  - cowboy-drill, angle-creation, heel-exposure

### 1.17 Achilles Lock Concepts
- Key concepts
  - Alignment emphasis (forearm/shin relationship) and “control then finish” discipline.
  - Structural errors (e.g., posture/hip action that degrades pressure line) reduce finish quality.
- Key cues
  - Fix alignment first; do not increase force on a bad pressure line.
- System tags
  - achilles-lock, alignment, control-before-finish

### 1.18 Knee Bar Concepts
- Key concepts
  - Knee bar commitment without control is framed as punishable; positional responsibility required.
  - Conceptually tied to maintaining control so defender cannot rotate/escape into counters.
- Key cues
  - Don’t jump to knee bars from unstable platforms; treat knee bar as an extension of control, not a shortcut.
- System tags
  - knee-bar, control-gates, counter-risk

### 1.19 Toe Hold Concepts
- Key concepts
  - Toe hold pressure is framed as coming on faster than heel hook pressure; used to force early reactions.
  - Directional breaking emphasis (toes driven down) is referenced as a core mechanic line.
- Key cues
  - Use toe holds to force a reaction that opens your next line rather than yanking without directional control.
- System tags
  - toe-hold, reaction-engine, fast-pressure

### 1.20 Heel Hook Concepts
- Key concepts
  - Inside vs outside heel hooks contrasted: inside framed as mechanically stronger/more forgiving; outside requires higher correctness for catastrophic breaks.
  - Strategic implication: finishing selection and urgency should reflect configuration precision demands.
- Key cues
  - Treat outside heel hook as precision-critical; don’t rely on “sloppy” mechanics that might still work on inside.
- System tags
  - heelhooks, inside-vs-outside, finishing-precision

## 2.0 Volume 2

### 2.1 Intro To Irimi Ashi Garami (0:00)
- Key concepts
  - Irimi ashi is presented as a primary “hub” entanglement because it gives strong control while reducing back-exposure risk compared to looser leg entanglements.
  - Strategic use-case: expose the heel reliably from a stable structure, then (often) transfer to outside ashi for higher-percentage catastrophic breaks.
- Position–structure
  - Priority connections are framed as “body-to-body + leg-to-leg” rather than “hands pulling a leg”: the structure should hold even without heavy hand effort.
- Key cues
  - The goal of the initial platform is: deny defender ability to freely come up and create back exposure, while keeping consistent heel exposure windows.
- System tags
  - irimi-ashi, hub-platform, heel-exposure, back-exposure-denial

### 2.2 Setting An Irimi Ashi Garami (1:53)
- Key concepts
  - Do not rely on arm-pulling against the defender’s leg; use your leg structure to create the pull and keep the entanglement tight.
  - “Heel-to-knee connection” is treated as a key retention concept (prevents the defender from peeling your foot off and separating your structure).
  - “Hip-to-hip connection” is treated as a second key retention concept (closes distance so the defender can’t create disengagement space).
- Position–structure
  - Entry/build sequence (as described)
    - Pull the opponent’s leg just far enough to shoot your knee behind their knee (set the bite) rather than yanking the leg with arms.
    - Use your knee pulling into your chest to draw them in (structure-driven pull).
    - Bring the foot up to the hip (establish the hip connection).
    - Pinch knees together with a slight extension on the controlling leg (stabilise the entanglement and prevent easy separation).
- Key cues
  - If your heel and knee drift apart, the defender’s hands can peel your foot off the hip easily; treat “heel-to-knee” as a constant maintenance task.
- System tags
  - irimi-ashi, heel-to-knee-connection, hip-to-hip-connection, entanglement-tightness

### 2.3 Stress Test (5:21)
- Key concepts
  - Stress testing is used to confirm the ashi structure is tight enough to survive real defensive motion long enough for breaking mechanics to matter.
  - The defender’s primary objective is framed as clearing the knee line by straightening and dragging the leg out; the attacker’s objective is to keep tightness and deny separation.
- Position–structure
  - Stress test behaviours referenced
    - Defender uses hands to pull/walk the leg backward to create separation and extract.
    - Defender rolls belly-down to change the alignment and try to disengage.
  - Attacker structural answers referenced
    - Pinch knees together and suck knees to chest to deny separation.
    - Raise hips slightly as the defender comes up (maintain bite and prevent “come-forward crush” pressure).
    - Maintain a strong back-heel action with the controlling leg as the defender rotates.
- Key cues
  - The test standard is: the structure should hold even with minimal hand use; if it fails, fix the leg/hip connections rather than “gripping harder.”
- System tags
  - stress-test, knee-line-denial, entanglement-integrity, retention-under-motion

### 2.4 Basic Achilles Lock (10:28)
- Key concepts
  - Achilles finishing is framed around keeping hands high and chin low while hips move away (avoid the common error of hips coming forward and chin drifting away).
  - Grip choice matters primarily for keeping hands high under defensive hand-fighting (avoid being pulled down).
  - The system frames achilles as both a finish and a controlling tool: if the defender can peel the foot off the hip, the position must be repaired before insisting on the finish.
- Position–structure
  - Finishing alignment cues referenced
    - Hands high (prevent defender from locking hands on your grip and dragging it down).
    - Chin low (keeps the breaking line tight).
    - Hips push away from opponent’s hips (creates the pressure line; belly-down orientation is referenced as a strong finishing option).
    - Elbow tight/in (used as a “keep the grip high” reinforcement when using certain grip configurations).
- Key cues
  - If the defender is peeling your foot off the hip, treat it as a positional failure signal: re-secure platform first, then finish.
- System tags
  - straight-ankle, hands-high, chin-low, hips-away, grip-management

### 2.5 Countering A Basic Extraction (14:18)
- Key concepts
  - “Kick and pull” extraction attempts are expected; the attacker response is framed as improving depth/tightness rather than chasing with arms.
  - The finish tightens as hips move away (you can create tightness without initially locking hands, then lock once the structure is loaded).
- Position–structure
  - Defensive behaviour referenced
    - Defender kicks foot deep then pulls back repeatedly to try to clear knee line and create disengagement.
  - Attacker response referenced
    - Reinforce the bite by pulling the knee to the chest (structure-driven), then load the finish by moving hips away.
    - After hips are far enough away to create tightness, bring hips in slightly as needed to maintain optimal alignment (tightness management rather than a single static pose).
- Key cues
  - When you feel the defender extracting, think “increase structural bite + hips away” rather than “chase the foot with arms.”
- System tags
  - anti-extraction, knee-to-chest-bite, hips-away-loading, tightness-management

### 2.6 Countering Forward Pressure With Ashi Garami And Elbow Position (16:48)
- Key concepts
  - Forward pressure (defender driving into you) is handled by (1) correct ashi structure and (2) immediate elbow-to-hip positioning once the achilles is locked.
  - Elbow-to-hip prevents the defender from “booting the foot through” while coming forward (boot + forward drive as a combined defensive theme).
- Position–structure
  - Key alignment referenced
    - The moment you lock the achilles, bring elbow down to hip (elbow/hip/ribcage glued concept appears later as well).
    - This elbow placement blocks the defender’s ability to kick the foot through/strip the bite as they drive forward.
- Key cues
  - If the defender is able to come forward and boot successfully, treat it as an elbow-position failure: correct elbow-to-hip immediately.
- System tags
  - forward-pressure-defense, elbow-to-hip, anti-boot, straight-ankle-control

### 2.7 Countering Forward Pressure With Post Ashi (19:18)
- Key concepts
  - When the defender peels the foot off the hip and/or forward pressure becomes significant, switching to post ashi is presented as a primary solution.
  - Post ashi is framed as producing a stronger break because you can push off the opponent’s hips while maintaining the heel/leg control.
- Position–structure
  - Switch trigger (as described)
    - Defender peels the foot off the hip.
    - Defender drives forward in a way that threatens to “shoot the leg through” and kill the bite.
  - Post ashi value
    - Creates a stable platform to push hips away and re-establish/maintain finishing alignment when the standard hip-foot connection is compromised.
- Key cues
  - When the original hip-foot connection is compromised, do not insist; switch platforms to preserve the breaking line.
- System tags
  - post-ashi, platform-switching, forward-pressure-defense, stronger-break-platform

### 2.8 Countering Forward Pressure With Belly Down Achilles (22:05)
- Key concepts
  - Belly-down achilles is presented as a strong conversion when the defender comes forward and the attacker can build height and drop hips to load pressure.
  - The finishing theme is “head up as hips come down” (create the belly-down pressure line).
- Position–structure
  - Conversion mechanics referenced
    - As defender comes forward, build height/post, widen knees, take elbow down toward hip, then bridge/drive into the belly-down finishing line.
    - Emphasis on keeping elbow/ribcage/hip glued while changing orientation (retain the integrity of the grip line).
- Key cues
  - When converting belly-down, treat “height + elbow discipline + hips down” as the non-negotiable sequence.
- System tags
  - belly-down-achilles, forward-pressure-conversion, elbow-discipline, posture-and-hip-line

### 2.9 Switching To Butterfly Ashi (25:27)
- Key concepts
  - Butterfly ashi is introduced as an answer when the defender peels the foot off the hip and steps/sits over the foot (a common forward-pressure + foot-strip reaction).
  - Post-butterfly ashi is referenced as a powerful variant option once you arrive in butterfly alignment.
- Position–structure
  - Scenario trigger referenced
    - Defender peels the foot off the hip (because it blocks their hip), then steps over/sits over the foot, forcing the position into a butterfly-foot relationship.
  - Key movement emphasis referenced
    - Move hips out and away while closing the right knee toward the floor (hip/knee coordination is framed as the stability mechanism).
- Key cues
  - If the defender repeatedly peels the foot and tries to scoot away, butterfly alignment is framed as a direct structural answer to stop that cycle.
- System tags
  - butterfly-ashi, post-butterfly, anti-foot-peel, hip-angle-management

### 2.10 Butterfly Ashi To Other Leg Entanglements (29:36)
- Key concepts
  - Butterfly ashi is treated as a transition hub: from the butterfly control line, you can transfer to outside ashi on either leg and access other entanglement families (including ushīrō entries mentioned).
  - Transfer logic includes switching the attacked leg (outside ashi on one leg → outside ashi on the opposite leg) as a deliberate system tool.
- Position–structure
  - Transition options referenced
    - Remove foot and transition to outside ashi on the same leg, or shoot heel across and pull into outside ashi on the opposite leg.
    - Spin/backstep pathways are referenced to reach cross ashi variations depending on how the defender squares/turns.
    - Ushīrō (including top ushīrō references) is mentioned as part of the transition space from butterfly/achilles grip control.
  - Control emphasis referenced
    - Control the space between opponent’s knees (knee-space control) as a stability principle while transitioning.
- Key cues
  - Butterfly is not a destination; it is used to regain control and then transfer into the entanglement you want (often outside ashi) on the leg that remains available.
- System tags
  - butterfly-ashi, transition-hub, leg-switching, outside-ashi-transfer, ushiro-entries

### 2.11 Achilles Heel Hook Dilemma (34:49)
- Key concepts
  - A dilemma is framed around defender foot behaviour once a controlling achilles is established:
    - If the defender “boots” hard, that is treated as a cue to move to heel hook exposure.
    - If the defender points toes (reducing heel availability), that increases achilles finishing availability.
  - Practical implication: you do not “choose” achilles vs heel hook in isolation; the defender’s foot response informs the correct attack branch.
- Position–structure
  - The controlling achilles is used as a handle to force predictable defensive foot behaviours that reveal the next best attack.
- Key cues
  - “Boot = heel hook cue” is explicitly stated as a recognition rule.
- System tags
  - achilles-heelhook-dilemma, foot-response-reading, branch-selection, threat-chaining

### 2.12 Finishing Mechanics (38:22)
- Key concepts
  - Finishing from irimi ashi is possible, but the common pattern is to transfer to outside ashi for higher-percentage breaking; both are addressed.
  - A “five major mechanics” model is referenced for reliable breaking alignment.
  - Core finishing requirement is a coupled-force idea: toes driven toward butt while heel is pulled toward chin (explicitly stated).
- Position–structure
  - Mechanical components explicitly referenced (best-effort capture)
    - Maintain heel-to-knee connection while establishing the breaking structure.
    - Use strong back-heel action with the controlling leg (pulling engagement).
    - Place/track the opponent’s heel into a consistent reference point (described using a “wristwatch” placement cue).
    - Apply coupled force: toes down toward butt + heel up toward chin.
    - Hip elevation/bridging as the final pressure amplifier (bridge without collapsing to the shoulder; aim between shoulder and elbow as described).
- Key cues
  - Do not treat breaks as slow “step-by-step” in live exchanges; the mechanics must stack smoothly and continuously once the window opens.
- System tags
  - irimi-finishing, coupled-force, heel-placement-cue, bridging-alignment, break-mechanics

### 2.13 Stress Test (45:32)
- Key concepts
  - Stress testing is repeated as a requirement when switching from achilles control into heel hook finishing: the platform must be resilient against the defender’s best responses.
  - High-hands requirement is reiterated as a safety/finish enabler (if hands are high and defender comes forward, they “break their own leg” framing is used).
- Position–structure
  - Testing focuses include
    - Defender attempts to come forward and crush.
    - Attacker confirms hands stay high and the ashi remains tight enough to finish immediately after the defender’s attempt resolves.
- Key cues
  - If you cannot keep hands high through the defender’s forward attempt, you are not ready to rely on that finish line live.
- System tags
  - stress-test, hands-high, forward-pressure-proof, transition-validation

### 2.14 Countering A Heel Slip With High Hands (46:54)
- Key concepts
  - Heel slip is framed as a common defender tactic when they can come forward and your hands are low.
  - Primary prevention is hands high immediately upon locking; this is positioned as both an anti-slip and a self-punishing trigger for forward pressure by the defender.
- Position–structure
  - Failure condition referenced
    - Low hands + imperfect ashi (common in live training) increases heel-slip likelihood when the defender comes forward.
  - Prevention condition referenced
    - Immediately raise hands high on lock; ensure ashi structure is set before relying on the finish.
- Key cues
  - “Hands low = heel slip risk” is presented as a simple recognition rule.
- System tags
  - heel-slip, hands-high, forward-pressure-punishment, finishing-discipline

### 2.15 Countering A Heel Slip With A Roll Through (48:28)
- Key concepts
  - Roll-through is presented as a reset/reboot solution when heel slip + forward pressure threatens to crush the attacker’s position.
  - The roll-through branches based on defender base: if they land seated/hip, reboot to irimi; if they build to knee, transition options open (ashi re-entry, X/reverse X references appear).
- Position–structure
  - Roll-through outcomes referenced
    - Roll partner through and reboot the system back into irimi ashi.
    - Use pendulum/figure-four style mechanics to sit the partner to the hip line (anti-crush recovery).
    - If partner comes up to a knee, transition to different control/entanglement families (reaping entry referenced; X/reverse X referenced).
- Key cues
  - When the position is “no good” (heel slipped and you’re being crushed), prioritise rebooting the platform over stubbornly clamping and getting flattened.
- System tags
  - roll-through, system-reboot, base-reading, anti-crush-recovery, transition-branching

### 2.16 Switching To Outside Ashi (52:34)
- Key concepts
  - Outside ashi is framed as the desired finishing platform for strong breaks; switching is used when the opportunity appears (leg can “sneak out” into outside ashi alignment).
  - Switching reduces the need for extended multi-roll sequences; instead of riding many rolls, you convert to outside ashi and finish from a stronger structure.
- Position–structure
  - Switch mechanics referenced (best-effort)
    - Bring knee to chest to maintain control, block at the hip, then switch to outside ashi where the break is stronger and more immediate.
- Key cues
  - When the positional window appears to transition to outside ashi, take it rather than forcing prolonged roll-chasing.
- System tags
  - outside-ashi, platform-switching, stronger-breaks, anti-multi-roll

### 2.17 Single Roll Theory (54:34)
- Key concepts
  - “Single roll theory” is presented as controlling the entanglement so the defender can roll through only once (not repeatedly).
  - The number/speed of defender rolls is framed as being determined by the quality of your ashi structure (platform determines escape bandwidth).
- Position–structure
  - Control mechanics referenced
    - Maintain hips connected to hips.
    - As defender initiates roll, point the knee toward the floor; bringing knees down/out to the floor line is used to shut down repeated rolling.
    - After the single roll, follow through and switch to outside ashi on the opposite side (single-roll → follow → outside ashi).
- Key cues
  - If the defender is rolling multiple times, treat it as a platform-control failure: your ashi is allowing too much rotational freedom.
- System tags
  - single-roll-theory, roll-limiting, hip-connection, knee-to-floor-control, follow-and-switch

### 2.18 Countering A Post Knee (59:41)
- Key concepts
  - Defender building to a posted knee is treated as a common intermediate base that changes the attacker’s control tasks and transition options.
  - A false grip on the defender’s knee is used as a control handle while opening the attacker’s knee to create threading/transition space.
- Position–structure
  - Control sequence referenced (best-effort)
    - Defender posts on a knee.
    - Attacker takes a false grip on the knee and opens their right knee to make space.
    - Use that space to thread the heel/leg across while pulling the defender’s knee across toward the attacker’s hip line (re-align for outside ashi landing).
- Key cues
  - When the defender is stable on a knee, treat knee control as the handle that lets you realign the entanglement rather than fighting the whole body.
- System tags
  - post-knee-base, false-grip-knee-control, threading-space, re-alignment

### 2.19 Figure 4 Switch If They Refuse To Roll (1:02:22)
- Key concepts
  - If the defender will not roll through, a full figure-four configuration is used to change the constraints and force a more favourable alignment.
  - The configuration emphasis is “heels down, knees flare/splay, hips lift,” combined with pointing knees opposite the defender’s preferred roll direction to deny their escape.
- Position–structure
  - Structural effects referenced
    - Figure-four lock tightens the leg configuration.
    - Heels down + knees flared + hips up creates a stronger control frame and changes the defender’s ability to turn back in and peel the foot off the hip.
- Key cues
  - If the defender is absorbing pressure but not giving you the roll you want, treat figure-four as the switch that changes the problem rather than endlessly “popping” pressure.
- System tags
  - figure-four-switch, anti-refusal, roll-denial, control-tightening

### 2.20 Breaking Mechanics (1:05:13)
- Key concepts
  - Belly-up breaking mechanics are contrasted with belly-down: belly-up has specific slippage problems when sweaty if you rely on certain forearm placements.
  - The solution is framed as changing the breaking direction and stacking leg mechanics (back heel + hips up + knees splayed) while controlling escape direction by pointing knees opposite the defender’s path.
- Position–structure
  - Mechanical stack elements referenced
    - Strong back-heel action.
    - Hips up.
    - Knees splay, then knees point opposite the defender’s escape direction.
    - Use elbow action (opening/arching) to straighten/align the leg as part of the breaking sequence (referenced in the context of managing slip and alignment).
- Key cues
  - If you feel slippage in sweaty conditions, treat it as a mechanics problem (direction + structure), not a “squeeze harder” problem.

  - You can read posture quickly and pick the correct branch without stalling.

  - #posture-dilemma #backside-50-50-entry #kneeling-opponent


### 6.10 Backside 50/50 hub → cross-waist / double 50 / criss-cross (31:20–41:08)

- Key concepts
  - Backside 50/50 + double 50 are described as **extremely strong breaking windows**, but more transitional than cross Ashi (harder to “hold forever”).
  - Opponent escape cluster:
    - High-leg over to return belly-up.
    - Step leg up and push back to relieve pressure.
    - Strip grips (often while getting broken).
  - Timing wedge: **invert knee before** they complete back-step/high-leg.

- Branching responses (high-density)
  - IF opponent high-legs to come forward:
    - Unlock feet as needed → place foot wedge in midline → **knee inversion** → often best: **cross-waist** off the transition → belly-down finish.
  - IF opponent steps leg up to push back:
    - Capture **far hip** first (anti-runaway handle).
    - If you can’t reach ankle due to size discrepancy, push **back of kneecap** to create turn.
    - Goal: create bend + cover into **double 50** for a short catastrophic breaking window.
  - IF opponent strips grips while you’re turning:
    - Maintain turning structure; they often lose while stripping.
  - IF opponent high-legs off double 50:
    - Option A: cross-waist.
    - Option B: follow into **bottom-side criss-cross Ashi** and finish belly-down.

- Irreversibility cue
  - Once “right knee points down” (turning structure set), treat it as **commitment**: continue turn; don’t reset.

- Failure signatures + fixes
  - Failure: you allow them to come forward to head/elbow before wedge is set.
    - Fix: knee inversion + wedging must happen **as** they initiate high-leg/back-step.

- Completion checks
  - You can convert backside 50/50 reactions into one of: cross-waist, double 50, criss-cross without giving head/elbow access.

- System tags
  - #backside-50-50 #double-50 #cross-waist #criss-cross-ashi #knee-inversion #far-hip-control


### 6.11 Following the roll (hips forward = they carry your weight) (41:08–44:32)

- Key concepts
  - After leg separation, opponent often bails into a roll.
  - Your job is not to be dragged—your job is to **drive weight into them** through the rotation:
    - Point knees opposite roll direction.
    - Hips come forward so roll becomes labored.
  - “Misdirectional” escape from 50/50 is treated as ineffective; if they roll wrong they expose themselves.
  - Missing the heel is not panic-worthy: restart cycle; back exposure is limited relative to looser entanglements.

- Decision rules
  - IF they roll, THEN follow immediately (no pause).
  - IF you can’t get cross-waist after roll, THEN at minimum create **extension + wedge** and re-enter breaking cycle.
  - IF legs open during roll landing, THEN consider transferring to **outside Ashi** instead of staying in 50/50.

- Completion checks
  - You can keep connection through roll and re-establish wedge/extension on the other side.

- System tags
  - #roll-follow #hips-forward #wedge-reset #50-50-to-outside-ashi


### 6.12 Mutual Ashi intro (the “outside heelhook 50/50” shootout) (44:32–47:31)

- Key concepts
  - Mutual Ashi = mutual outside heelhook exposure; legs are split so you can’t hide feet with normal leg-crosses.
  - Strategic preference: avoid choosing it; prefer transferring to **far-hip Ashi** when possible.
  - Typical entry causes: losing a leg pummel, leaving a leg behind; some half-guard elevation scenarios.

- Completion checks
  - You identify Mutual Ashi as unstable and immediately seek: “go last” + transfer pathway.

- System tags
  - #mutual-ashi #shootout #outside-heelhook-risk


### 6.13 Going last (initiative timing rule) (47:31–50:32)

- Key concepts
  - In mutual-Ashi shootouts, first committed exposure (falling/turning to expose heel) often exposes your own heel.
  - Preferred strategy: let opponent “go first,” then counter so you end with the last meaningful action.

- Decision rules
  - IF opponent drops/turns first to expose, THEN treat as their error → counter exposure and begin your breaking cycle.

- System tags
  - #initiative-timing #go-last #shootout-management


### 6.14 Rolling through (force outside Ashi via heel elevation + knee lever) (50:32–54:30)

- Key concepts
  - Resolution method: elevate heel off floor (reduces base), lever knee across, bump body off-line → lock → apply pressure → force roll → transfer to **outside Ashi** → finish.
  - Toe hold can accelerate the reaction (break pressure comes on sooner) to trigger the roll/transition.

- Operational checkpoints
  - “Heel off the floor” before you commit to the roll-through exposure.
  - “Catch then lock immediately” to deny re-base time.

- Decision rules
  - IF they force you to a hip, THEN raise hips and re-apply elevation mechanics to regain heel height.
  - IF toe hold is available and you need faster reaction, THEN use it to induce roll and feed to outside Ashi.

- System tags
  - #roll-through #heel-elevation #outside-ashi-transfer #toe-hold-accelerant


### 6.15 Far-hip Ashi (preferred safety lock out of mutual Ashi) (54:30–58:12)

- Key concepts
  - Far-hip Ashi is the preferred conversion because it:
    - Makes it hard for them to attack your legs,
    - Puts “two legs in front of them” to block handfighting access,
    - Narrows their options to: lean back, pass legs across (still under break), or roll through (you follow to outside Ashi).
  - Key safety benefit: even if heel slips and they come back, your feet are still safer when ankles are crossed/locked far-hip.

- Decision rules
  - IF in mutual Ashi and far-hip is reachable, THEN prioritize far-hip lock before prolonged exposure work.
  - IF they roll through, THEN follow and transfer to outside Ashi.

- System tags
  - #far-hip-ashi #safety-lock #anti-handfight #outside-ashi-endpoint


### 6.16 Gripping (engine vs transmission; climb to tighter circles) (58:12–01:10:55)

- Key concepts
  - Control first: Ashi structure (engine) precedes grip sophistication (transmission). Grips can produce “false positives” if your Ashi is loose.
  - Circle principle: smaller circle = tighter lock; but you can’t always start at tightest.
  - Progression model: **connect hands first**, then climb tighter:
    - ten-finger → palm-to-palm → wrist-to-wrist → (reverse) figure-four when appropriate.

- Grip families + operational use
  - Ten-finger
    - Use when floor blocks tighter connections; establishes connection.
    - Diagnostic: if you can break with ten-finger, mechanics are strong.
  - Palm-to-palm
    - Intermediate tightening step after ten-finger.
  - Wrist-to-wrist
    - Tight, low slippage; commonly preferred for belly-down finishing.
  - Reverse figure-four
    - Strong, but switching can risk slippage if you must release tension mid-transition.
    - Often preferred when belly-up / slippage risk is lower and you can safely switch.
  - False grip / wrist-watch grip
    - Control grips (not final finishing grips): prevent partner from kicking hands off, especially in 50/50.

- Decision rules (high utility)
  - IF floor blocks palm-to-palm/wrist-to-wrist, THEN ten-finger first → use back-heel to pull off shoulder → climb.
  - IF finishing belly-down, THEN default preference: wrist-to-wrist (use ten-finger/palm-to-palm as stepping stones).
  - IF belly-up and slippage risk is lower, THEN reverse figure-four becomes attractive; mechanics shift to “crunch-toes-to-butt / heel-to-chin” style (more like belly-down).
  - IF switching grips requires releasing critical tension while opponent is driving weight in, THEN avoid the switch (stay wrist-to-wrist).

- Completion checks
  - You can explain your grip choice as a constraint solution (floor, orientation, slippage risk), not preference-only.

- System tags
  - #grip-progression #circle-principle #wrist-to-wrist #reverse-figure-four #false-grip
