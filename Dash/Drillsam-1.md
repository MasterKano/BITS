## Concept Hierarchy Tree — Back Crucifix (Teaching Spine + Volume Pointers)

### Notes (how to use this)
- Brackets indicate where to find the primary instruction for that item (e.g., `[V2]` = Volume 2).
- Coach and teach by **invariants**: identify which obligation is failing (I1/I2/I3), then route to the relevant module or problem-solve layer.
- Structure classes around a repeating loop: **Acquire → Consolidate → Maintain → Recover** (then finish selection).

---

### Back Crucifix System

- **1) System Goal & Identity** `[V1]`
  - **Goal:** a back-control variant built around immobilization → predictable finishes `[V1, V4]`
  - **How it differs from standard back control** (control priorities are reassigned) `[V1]`  
    - *Teaching note:* teach this first so students don’t apply rear-mount habits that don’t fit.

- **2) Non-Negotiables (Invariants / Control Obligations)** `[V2, V3]`
  - **I1:** Far arm is functionally immobilized (no posting / peeling / turning assistance) `[V2]`
  - **I2:** Near shoulder is pinned/managed (limits turn-in + rotation) `[V3]`
  - **I3:** Your alignment prevents their sit/stand/turn escape sequences `[V3]`  
    - *Coaching note:* “Which invariant is failing?” is a better live cue than “Which move next?”

- **3) Control Engine (how you satisfy I1–I3)**
  - **3.1 Far Arm Module (Primary control dial)** `[V2]`
    - **Acquisition → Consolidation → Maintenance → Recovery** `[V2]`
    - **Governing mechanic:** *Wedge / Hook / Prop* principle `[V2]`  
      - *Teaching note:* this is the mechanical center; everything else plugs into it.
  - **3.2 Near Shoulder Module (Secondary control dial)** `[V3]`
    - **Acquisition → Consolidation → Maintenance → Recovery** `[V3]`  
      - *Teaching note:* teach after far arm; it’s the common “leak.”
  - **3.3 Positional Organization Model: “Three by Six”** `[V3]`
    - **Purpose:** organizing map for maintaining the position and choosing controls `[V3]`
    - **Teaching approach:** categories → examples → resistance (avoid rote memorization) `[V3]`

- **4) Problem-Solving Layer (predictable opponent reactions)** `[V3]`
  - **P1: Seated Arm Sit (avoid + recover)** `[V3]`  
    - *Coaching note:* treat as an early-warning problem—fix it before it becomes a full reset.
  - **P2: Locked Hands (breaking protocol)** `[V3]`  
    - *Coaching note:* keep the position first; break the lock without donating the escape.
  - **P3: Opponent rises / stands (control adaptation rules)** `[V3]`  
    - *Coaching note:* when they elevate, your job is to preserve I1–I3 while their leverage changes.

- **5) Finishing Layer (when control is stable, how you end)** `[V4]`
  - **F1: Strangle family** `[V4]`
  - **F2: Garrote** (subset / variant) `[V4]`
  - **F3: Arm lock family** `[V4]`
  - **F4: “Totality Principle” (finishing framework)** `[V4]`
    - *Teaching note:* finishes are connected; switch when resistance predicts the next opening.
    - *Coaching script:* “Primary finish attempt → secondary finish → return-to-control.”

- **6) Entry Layer (how you arrive without breaking the control model)** `[V5–V7]`
  - **E1: From top turtle (behind elbows)** `[V5]`
    - Sequencing: **breakdown-first vs crucifix-first** `[V5]`
    - Dynamics: **fall back vs fall forward; anti-roll; vs referee position** `[V5]`
  - **E2: From top turtle (in front of elbows)** `[V6]`
    - Named routes: **knee block go-behind; heel-and-spin; front headlock inversion; chest lock route** `[V6]`
  - **E3: From bottom guard** `[V6]`
    - Named routes: **seated heist → front headlock; supine shin-guard method** `[V6]`
  - **E4: From top guard** `[V7]`
    - Named routes: **half guard top route; top seated guard route** `[V7]`

- **7) Interfaces (integration with adjacent systems)** `[V3]`
  - **Rear mount ↔ back crucifix** (transition logic) `[V3]`
  - **Crucifix ↔ T-kimura** (transition logic) `[V3]`
  - **Optional submission add-on: reverse omoplata** (where it fits in finish selection) `[V7]`
