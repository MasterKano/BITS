# Meta — Systems Rules (Canonical)

## Purpose

`SYS/meta/` contains **cross-cutting rules and gates** that apply across multiple domains (leglocks, top control, back takes, passing).

- These pages exist to prevent repeating the same rules in every system file.
- Other SYS pages should link here instead of duplicating principles.

## How to use

- When updating any SYS page, check whether the concept is:
  - **Domain-specific** (belongs in `SYS/leglocks/`, `SYS/top/`, `SYS/back/`, etc.), or
  - **Cross-cutting** (belongs here).
- Prefer linking to these pages from other SYS pages under:
  - “Links”
  - “Prerequisites”
  - “Gates”
  - or “References”

## Canonical pages

- `conversion-loop.md`
  - Reaction-led pass/back chaining; “no reset” rule; how to end every exchange in advantage.
- `cranial-shift.md`
  - Head/shoulder control as the gate that turns “past the legs” into stable pins/passes.
- `back-completion-criteria.md`
  - Backtake completion standards (upper-back connection, centre-line alignment, hips-inside-knees).
- `constraint-gates.md`
  - Constraint-first permissions (Achilles/foot control, heel-line safety) that govern when transitions are allowed.

## Operating rules

- **No duplicates:** if a meta topic exists, update it rather than creating a new page.
- **SYS stays durable:** keep meta pages as stable rules/checklists, not per-instructional transcripts.
- **Sources:** each meta page should link to contributing instructionals (VN/BIO) in its Sources section.
