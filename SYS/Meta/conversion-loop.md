# Conversion loop

## Purpose

A repeatable decision loop for converting leg entanglements into **top advantage**:
- back takes when the opponent turns away
- pins/passes when the opponent turns toward
- no resets to neutral after a denied attempt

## Core idea

- Leg entanglement is an **entry hub**, not a destination.
- You are running a forced-choice fork:
  - **Turn away** to escape pressure → expose back
  - **Turn toward** to defend back → concede pin/pass progression
- If neither lane is stable yet, you land in a **stabilizer hub** and re-run the fork.

                          |        |
          turn toward ----+        +---- turn away

              v                            v

              |
              v

        (camping / north-south / ride / tight waist / body lock)
~~~


## Key positions

- Starting hubs (examples):
  - irimi ashi
  - outside ashi (forward phase)
  - cross ashi
  - inside ashi / 50-50 (escape-to-convert hubs)
- Stabilization platforms (common landings):
  - camping
  - north-south
  - cross-body ride
  - tight waist
  - body lock / side body lock

## Decision rules (IF/THEN)

- IF you are in a leg hub AND safety gates are satisfied -> THEN begin conversion (do not stall).
- IF the opponent **turns away** under pressure -> THEN attach chest-to-upper-back (connection before hooks).
- IF the opponent **turns toward** to deny attachment -> THEN accept chest-to-chest and progress passing/pinning.
- IF a backtake attempt is **denied / slipping** -> THEN enter a stabilizer hub immediately (no reset).
- IF a pass/pin attempt stalls but control is stable -> THEN increase pressure to force a turn (re-run the fork).
- IF you cannot achieve stable pin OR stable attachment -> THEN stabilize first, then branch again.
- IF they attempt turtle as pressure rises -> THEN capture the attempt early (anchor-first), then branch pass/back.
- IF you are “past legs” but cannot progress -> THEN you failed cranial shift; establish it before continuing.

## Reaction triggers (what you are trying to force)

- Turn-away (fleeing pressure) -> opens back attachment
- Turn-toward (facing to defend back) -> concedes pin/passing advancement
- Turtle attempt -> capture early -> branch to back or flatten/pass
- Inversion attempt -> manage ankle/leg line early -> return to fork

## Failure signatures + fixes

- Failure: you “win the legs” but stall with no progress.
  - Fix: pick a lane immediately—attach back OR enter stabilizer hub and force the turn.
- Failure: you float between pass/back and they re-square.
  - Fix: commit to the lane dictated by the turn; stabilize before advancing.
- Failure: you chase hooks without upper-back connection.
  - Fix: rebuild chest-to-upper-back + centre-line alignment; hooks are downstream.
- Failure: denied attempt → you reset to neutral.
  - Fix: denied attempt is the trigger to stabilize (camping / north-south / ride / tight waist).

## Completion checks

- Each exchange ends in one of:
  - stable back attachment (upper-back connection + alignment)
  - stable pin/passing platform (cranial control present)
  - stabilized intermediate hub that forces a predictable reaction
