# Back — Control & Connectors (Canonical)

## Purpose

`SYS/back/` contains the canonical **back control and connector systems** used to:
- convert turn-away reactions into stable back attachment,
- finish backtakes without scrambling,
- and link common grips (head-and-arm, kata gatame, kimura) into back control.

These pages are reused across instructionals; do not duplicate them elsewhere.

## How to use

- Use these pages when your sequence produces:
  - turn-away reactions (back lane),
  - turtle/quadpod transitions,
  - head-and-arm/kimura/kata-gatame controls that can convert to the back.
- Link to meta standards rather than duplicating them:
  - `../meta/conversion-loop.md`
  - `../meta/back-completion-criteria.md`
  - `../meta/constraint-gates.md`

## Canonical pages

- `head-and-arm.md`
  - Head-and-arm back control: retention, re-capture, and conversion rules.
- `kata-gatame-bridge.md`
  - Kata gatame as a connector to back takes / stabilizing turns.
- `kimura-to-back.md`
  - Kimura grip pathways to back takes and to passing outcomes.

## Operating rules

- Connection before hooks: use `../meta/back-completion-criteria.md`.
- If attachment slips, do not scramble—drop into a stabilizer hub (`SYS/top/`) and re-run the conversion loop.
- Add Sources links to contributing instructionals (VN/BIO) as you incorporate them.
