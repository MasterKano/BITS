# Kimura to back

## Purpose

A connector system using kimura control to:
- prevent re-square during turn battles,
- force predictable reactions (turn-toward / turn-away / turtle),
- convert into stable back attachment or stable pin/passing outcomes.

## Core idea

- Kimura is a **shoulder-control hub**.
- It is used when the opponent’s primary defense is shoulder rotation and re-facing.
- The kimura grip is a control engine that lets you:
  - freeze the shoulder line,
  - steer rotation,
  - and choose your conversion lane (back or pass) based on the reaction.

## Key positions

- Kimura control (primary hub)
  - Shoulder line captured; opponent cannot freely rotate to face you.
- Kimura → back connector
  - As they turn away under shoulder control, you keep connection and attach upper back.
- Kimura → pass connector
  - If they keep turning in, you stabilize chest-to-chest and pass while shoulder is controlled.
- Kimura → tight waist
  - If they turtle/quadpod to avoid the shoulder battle, tight waist becomes stabilizer.
- Kimura → top stabilizer
  - If grip is threatened or slipping, you drop into camping/north-south to re-stabilize rather than scramble.

## Entries

- From top ushiro / top-side leglock conversions
  - When kimura appears during top leg entanglement conversions, use it as the bridge to back/pass.
- From denied backtakes
  - If they turn-in hard to deny hooks, kimura control can freeze the shoulder line and restart the fork.
- From top control hubs (camping / north-south / ride)
  - When frames + turn-in are preventing advancement, kimura can capture the shoulder and remove re-square.

## Key cues (operational)

- “Shoulder line wins the turn”: kimura is about controlling rotation, not chasing a finish.
- “Elbow management matters”: if the elbow line escapes, shoulder control degrades.
- “Connection stays”: if chest contact breaks, expect scramble.
- “Turn decides the lane”: toward = pass; away = back; turtle = tight waist.

## Control gates (must be true before branching)

### 1) Shoulder line controlled
- They cannot rotate shoulders freely to face you.
- If shoulder can rotate, kimura control is not functioning.

### 2) Elbow managed
- Elbow line is controlled enough that they cannot easily slip the shoulder free.
- If elbow is drifting to freedom, fix it before transitioning.

### 3) Chest contact maintained
- You are attached enough that rotation must break your control to escape.
- If you are reaching with arms only, you will lose the turn battle.

### 4) No clean rise
- They cannot build height/stand cleanly without you collapsing it.
- If they rise, treat it as a stabilizer trigger (tight waist/breakdown).

## Decision rules (IF/THEN) — lane-by-lane

### A) Establishment
- IF kimura grip is available during a turn battle -> THEN establish shoulder control first (shoulder line gate).
- IF elbow begins escaping -> THEN fix elbow management before trying to convert.
- IF chest contact is breaking -> THEN re-close distance before transitioning.

### B) Branch: turn-toward (faces hard / frames)
- IF they keep turning toward -> THEN accept pass/pin lane:
  - stabilize chest-to-chest,
  - use shoulder control to deny re-square while you pass.
- IF frames block progress -> THEN re-win cranial control and re-angle; do not drive square.

### C) Branch: turn-away (runs/rolls)
- IF they turn away under kimura control -> THEN switch to back lane:
  - close distance to upper back first,
  - satisfy back completion criteria,
  - then insert hooks/body triangle.
- IF distance opens during the switch -> THEN re-stabilize in camping/ride and re-attach; do not chase hooks from far.

### D) Branch: turtle / quadpod
- IF turtle/quadpod forms -> THEN tight waist trigger:
  - breakdown first,
  - then branch pass/back as reaction appears.
- IF they build height while you hold kimura -> THEN collapse the rise before any other goal.

### E) No scramble rule
- IF kimura control is slipping and you are losing top -> THEN drop to a top stabilizer (camping/north-south/ride) and rebuild.
- IF you cannot keep shoulder control through rotation -> THEN ride the rotation (cross-body ride) rather than forcing the transition.

## Opponent counters + immediate answers

- Counter: turn-in hard + frames to re-square.
  - Answer: keep shoulder line controlled; accept pass lane and progress.
- Counter: explosive turn-away to create distance.
  - Answer: maintain chest contact; if distance opens, re-stabilize then re-attach.
- Counter: turtle/quadpod.
  - Answer: tight waist/breakdown; avoid hook chasing on mobile turtle.
- Counter: elbow line slips to freedom.
  - Answer: re-capture elbow control before converting lanes.

## Failure signatures + fixes

- “I have kimura but they still re-square.”
  - Fix: shoulder line gate is failing or elbow line escaped; re-establish both before moving.
- “I switch to back and lose them.”
  - Fix: you broke connection; attach upper back first, hooks second.
- “I insist on back when they keep turning in.”
  - Fix: turn-toward = pass lane; take it.
- “Grip fight turns into scramble.”
  - Fix: no scramble rule—drop into top stabilizer and rebuild.

## Completion checks

- They cannot rotate shoulders freely without breaking your control first.
- You can force:
  - continued turn-in (pass lane),
  - turn-away (back lane),
  - turtle/quadpod (tight waist),
  while maintaining top advantage.
- If back lane occurs, you can satisfy back completion criteria before hook pursuit.
