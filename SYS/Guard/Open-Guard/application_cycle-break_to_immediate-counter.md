# Application — Cycle Break → Immediate Counter

## 1. Purpose
Convert retention success into initiative. This module defines:
- what qualifies as a cycle break,
- what must happen immediately after,
- and how to prevent the “defend then pause” failure pattern.

## 2. Definition: Cycle Break (must satisfy all)
A cycle break exists only when:
- opponent is re-centered (no dominant angle)
- barriers are rebuilt (legs/frames between bodies)
- orientation restored (feet or knees facing)
- hip line is no longer threatened

If any are false, you are still in the defensive cycle.

## 3. Mandatory Action
On cycle break:
- initiate counter-offense immediately (no reset)

Fast selector (Golden Rule):
- head high → legs
- head low → arms/head + go-behind family

## 4. Operational Rules
- Counter is not optional; it is the completion of the defensive cycle.
- Counter must be structurally valid:
  - maintain attachment (hands + feet redundancy)
  - obey hands-down gate for spin/rotation entries
- If opponent tries to disengage after cycle break:
  - follow and reattach (anti-exit governance)
  - do not accept range reset

## 5. Failure Signatures
- “I defended and felt safe, then got passed again” → no counter; cycle incomplete
- “I countered but got smashed” → entry committed without validity (hands-down gate)
- “He backed out and we restarted” → anti-flee/backstep governance missing
