# Open Guard — Master Operating System (Controller)

## 1. Purpose
A controller system for Open Guard that:
- prevents passing by denying pass-building requirements early, and
- converts every successful defensive cycle into immediate counter-offense.

This page is the top-level operating layer: chain diagnosis, gates, routing, and practical training rules.

## 2. Inputs / Preconditions
- You can maintain **orientation** (feet or knees facing) or recover it within one beat.
- You can establish/re-establish at least one **true handle** (Section 10).
- You can switch between **mobility** (re-square) and **structure** (frames) based on hip line threat.

## 3. Outputs / Success Criteria
You are succeeding if you consistently produce one or more:
- opponent kept **in front** (angle denied),
- pass chain interrupted (forced re-step/re-grip/re-square),
- hip line threat avoided or resolved (defensive cycle → cycle break),
- base compromise forced (**post/widen/forced step**),
- clean disengage/reset prevented,
- cycle break followed by **immediate counter initiation**.

## 4. Core Model / Engine

### 4.1 Master Loop
**READ → CONNECT → DENY → RECENTER →**
- **(BASE BREAK → ENTER → HUB → GOVERN EXITS → FINISH)**, or
- **(DEFENSIVE CYCLE → CYCLE BREAK → COUNTER → RECENTER)**

Definitions:
- **READ:** intent + commitment (energy + posture context)
- **CONNECT:** true handle + redundancy (hands + feet)
- **DENY:** break the *current requirement link* (not “a pass”)
- **RECENTER:** opponent in front; barriers between bodies
- **BASE BREAK:** force post/widen/forced step (hands-down gate)
- **ENTER:** commit to entry family matched to range
- **HUB:** stabilize in a platform that suppresses best opponent exit
- **GOVERN EXITS:** deny reset (backstep/flee/closure/backside)
- **DEFENSIVE CYCLE:** mandatory under hip line threat
- **CYCLE BREAK:** restored state enabling counter-offense
- **COUNTER:** immediate threat application (Golden Rule selector)

### 4.2 Domain Progression Chain Table (Open Guard Passing Chain)
Identify the link being built *now* and deny it before the next link opens.

| Link | What you read (signal) | What you deny (action) |
|---|---|---|
| Distance | space collapsing; your legs displaced from inside line | reinsert barriers; knees/feet between bodies; re-center |
| Grip | stable anchors forming (ankle/pant/upper-body control) | strip/downgrade; build your own true handle + redundancy |
| Angle | outside knee line forming; hips not squared | crossover/scoot/pendulum to re-square; enforce orientation |
| Level | posture compressing; shoulders dropping | frames high/low; turn-to-side early; deny shoulder line |
| Penetration | hip line threatened; legs cleared to hips | defensive cycle immediately; recover barriers then square |
| Pin | shoulder line flattened; chest-to-chest consolidation | prevent flattening; rebuild frames; re-guard/reinsert legs |

### 4.3 Selector Pack (short rules; depth lives in linked files)
Use these to avoid wrong-family decisions:

- **Dynamic Energy (commitment read):**
  - forward+push = pressure build → structure earlier; protect hip line
  - backward+pull = reset/backstep → follow + keep true handle; deny disengage
  - backward+push = shove-to-clear → reinsertion first; then re-center + attach ankle
  - forward+pull = strip/bait while advancing → reattach leg line; re-square hips

- **Three Laws (posture context):**
  - kneeling: base-break window vs drive; don’t treat kneeling as harmless
  - standing: watch backstep/disengage; don’t accept reset
  - head height: head high → legs; head low → go-behind/upper-body routes

### 4.4 Routing Heuristics (don’t duplicate sub-systems)
- If **in front** and stable: choose *mobility* solutions first (re-square + barriers).
- If **hip line threatened**: defensive cycle until cycle break, then counter.
- If **base compromised**: commit to entry connectors; stabilize in a hub before chasing finishes.
- If opponent’s best defense is **reset**: prioritize anti-exit governance over “better grips.”

## 5. Gates (override rules)

### 5.1 Gate A — Hip Line Gate (phase switch)
**Question:** Is the opponent at/past your hip line?

- **NO:** mobility dominates; deny angle before penetration.
- **YES:** you are in **DEFENSIVE CYCLE** until cycle break.

**Default action:** frame high/low → turn-to-side → shrimp/recover barriers → re-square.

**Cycle Break (all required):**
- opponent re-centered (no dominant angle),
- barriers rebuilt (legs/frames between bodies),
- orientation restored (feet or knees facing),
- hip line no longer threatened.

### 5.2 Gate B — Hands-Down Gate (entry validity)
**Question:** Is their base truly compromised (post/widen/forced step)?

- **NO:** no committed rotation/entry under stable posture.
- **YES:** entry window is open; commit.

**Default action:** off-balance until post/widen occurs → start entry inside the window.

### 5.3 Gate C — Orientation Rule (retention integrity)
At all times:
- feet or knees must face the opponent,
- if one is displaced, the other replaces it immediately.

**Default action:** re-square hips (crossover/scoot) + reinsert feet/knees facing before any other goal.

## 6. Opponent Reactions → Responses

### 6.1 Top-6 Playbook
1) **Mobility circle (low compression, circling)**
   - Response: foot pummel + crossover/scoot → re-center.
2) **Shove-to-clear then retreat**
   - Response: immediate reinsertion + re-center; attach ankle line to stop reset.
3) **Kneeling drive pressure**
   - Response: frames (high/low) + turn-to-side + shrimp → rebuild → re-run base break.
4) **Backstep reset / disengage**
   - Response: follow + maintain true handle; containment hub if already entangled.
5) **Heavy leg / high leg defence**
   - Response: maintain line control; occupy space; upgrade to containment if repeated.
6) **Leg closure / backside flattening**
   - Response: deny closure by occupying space; win legs-vs-hands push; reinsert barriers.

### 6.2 Exit Governance (reset denial rules)
- **Backstep:** follow immediately; keep ankle/heel line; re-center hips (don’t hand chase).
- **Flee / hard retreat:** redundant attachment (hand+foot) so retreat is slow.
- **High leg / heavy leg:** occupy space first, then climb; never climb on thin contact.
- **Leg closure:** deny by filling space; don’t allow “empty wedge.”
- **Backside flattening:** legs must out-push hands; rebuild frames; re-square.

## 7. Failure Signatures → Fix
- **Late defense:** hip line reached before structure → apply Gate A earlier; turn-to-side sooner.
- **Dead feet:** touching without control → reinsert true barriers/hooks; regain orientation first.
- **Hand chasing:** arms lead, hips lag → re-square then reinforce with hands.
- **Spin under stable base:** Gate B violated → base break longer; no rotation until post/widen.
- **Thin entries:** attachment breaks on one step → upgrade to true handle + redundancy.
- **Stop-pass-stop:** cycle break without counter → counter begins immediately on cycle break.

## 10. True Handle Checklist (prevent thin attachment)
A “true handle” is present only if the connection meets these tests:
- **Survival:** survives one full opponent step without breaking.
- **Line control:** ankle/heel line > shin line > foot touch.
- **Redundancy:** ≥2 points across hands/feet/legs.
- **Orientation:** you can keep feet/knees facing while holding it.
- **Recenter:** it helps keep them in front (prevents angle runaround).

If any test fails: reattach to ankle/heel line, add redundancy, re-center, then climb.

## 11. Drills and Games (Game Cards)

### 11.1 Keep Him In Front
- **Start:** passer standing; defender seated open guard.
- **Defender wins:** prevent **outside knee line** for **20s** while keeping any contact.
- **Passer wins:** **outside knee line** then **hip line touch** or **pin**.
- **Rules:** defender cannot stand; passer must keep moving.
- **Reset:** hip line touch / pin / timer.
- **Rounds:** 8×20s, switch.

### 11.2 Hip Line Escape (Defensive Cycle Only)
- **Start:** passer has late-stage angle near hip line; no pin yet.
- **Defender wins:** reach **cycle break** and hold squared guard **3s**.
- **Passer wins:** **pin** or flattened shoulders **3s**.
- **Rules:** defender uses frames + turn-to-side + shrimp until squared (no entries).
- **Reset:** 3s hold / pin.
- **Rounds:** 10 reps each, switch.

### 11.3 No Free Reset (Anti-Exit)
- **Start:** range with light contact allowed.
- **Defender wins:** establish a **true handle** and keep any contact **15s**.
- **Passer wins:** **disengage to two steps** with no contact.
- **Rules:** passer prioritizes retreat/backstep; defender must follow immediately.
- **Reset:** timer / disengage.
- **Rounds:** 8×20s, switch.

### 11.4 Hands-Down Window
- **Start:** passer standing stable.
- **Defender wins:** force **post/widen/forced step** then start entry within **2s**.
- **Passer wins:** stable base + clears/shucks contact for **20s**.
- **Rules:** committed entry before base compromise = loss of rep.
- **Reset:** entry start after base compromise / timer.
- **Rounds:** 10 reps each, switch.

### 11.5 Clear-and-Go (Shove-to-Clear)
- **Start:** passer standing; defender seated.
- **Defender wins:** reinsert barriers + re-center; hold “in front” **3s**.
- **Passer wins:** **outside knee line** **3s**.
- **Rules:** passer may only shove legs aside + circle (no forward pressure).
- **Reset:** 3s hold by either side.
- **Rounds:** 8×20s, switch.
