# Open Guard — Master Operating System (Controller)

## 1. Purpose
A controller system for Open Guard that:
- prevents passing by denying pass-building requirements early, and
- converts every successful defensive cycle into immediate counter-offense.

This page defines the master loop, gates, selection rules, interfaces to subordinate SYS modules, failure diagnostics, and training tests.

## 2. Canonical Loop
**READ → CONNECT → DENY → RECENTER →**
- **(BASE BREAK → ENTER → HUB → GOVERN EXITS → FINISH)**, or
- **(DEFENSIVE CYCLE → CYCLE BREAK → COUNTER → RECENTER)**

Definitions:
- **READ:** opponent intent + commitment (energy + posture context)
- **CONNECT:** establish a true handle + redundancy (hands + feet)
- **DENY:** break the pass requirement currently being built (not “a pass”)
- **RECENTER:** restore alignment (opponent in front; barriers between bodies)
- **BASE BREAK:** force posting / widened base (validity for committed entries)
- **ENTER:** lowest-complexity entry matching range + posture
- **HUB:** stabilize in a platform that suppresses the opponent’s best exit
- **GOVERN EXITS:** prevent reset (backstep/flee/heavy-high/closure/backside)
- **DEFENSIVE CYCLE:** mandatory when hip line is threatened (Gate A)
- **CYCLE BREAK:** state that permits counter-offense (Section 3.1)
- **COUNTER:** immediate threat application (Golden Rule selector)

## 3. Master Gates (override rules)

### 3.1 Gate A — Hip Line Gate (phase switch)
**Question:** Is the opponent at/past your hip line?

- **NO (in front of hip line):**
  - mobility solutions dominate (pummel/crossover/pendulum/scoot)
  - objective: keep them in front; deny angle before penetration
- **YES (at/past hip line):**
  - you are in **DEFENSIVE CYCLE**
  - frames are structural; turn-to-side + shrimp are primary
  - objective: rebuild barriers + recover facing until cycle break

**Cycle Break (must satisfy all):**
- opponent re-centered (no dominant angle)
- barriers rebuilt (legs/frames between bodies)
- orientation restored (feet or knees facing)
- hip line no longer threatened

### 3.2 Gate B — Hands-Down Gate (entry validity)
**Question:** Is their base truly compromised (post/hands-down/widened base/forced step)?

- **NO (upright stable base):**
  - keep off-balancing; keep connection
  - do **not** commit rotations/spin-unders under stable posture
- **YES (base compromised):**
  - entry window is open; commit to entry/hub selection

### 3.3 Gate C — Orientation Rule (retention integrity)
At all times:
- **feet or knees must face the opponent**
- if one is displaced, the other replaces it immediately
- “double loss” (neither facing) is a red alarm: angle → penetration → hip line follows

## 4. Passing Model (what you defend)
Passing is a requirements chain:
**Distance → Grip → Angle → Level → Penetration → Pin**

Retention job:
- identify which link is being built now,
- break one link early,
- re-center and rebuild barriers,
- counter immediately on cycle break.

## 5. Range + Context Selectors (fast rules)
These are selectors; gates still override them.

### 5.1 Dynamic Energy (commitment)
- forward push → treat as pressure build: protect hip line; deny distance/level
- backward pull → treat as exit: follow; maintain attachment; contain if entangled
- backward push → shove-to-clear: foot pummel + re-center immediately
- forward pull → strip/bait while advancing: maintain leg-line handle; re-square hips

### 5.2 Three Laws (posture)
- **Kneeling:** shoulders vs hips (base-break window vs withdrawal)
- **Standing:** toes vs heels (drive-in vs backstep/disengage)
- **Head height:** head high → legs; head low → arms/head + go-behind

## 6. Entry Families (selection by range)
Choose what matches the moment; do not force a preferred family.

- **Distance:** 2-on-1 ankle / partial inversion connectors / shin-to-shin
- **Kneeling:** single/double/reverse double; cross-catch → hip pin
- **Standing bridges:** X-guard / RDLR / HQ (must satisfy hands-down gate)

## 7. Hub Selection (stabilize before finishing)
Hub choice is governed by the opponent’s best exit.

- forward drive pressure → **inside senkaku** (forward barrier)
- turn-away / disengage → **50–50 / double 50** (containment)
- backside flattening pressure → **criss-cross** (backside stability + breaking alignment)

## 8. Exit Governance (no free reset)
Assume the opponent’s primary defense is **reset**, not “fight in place.”

Common exits/defenses:
- backstep
- flee the mat / hard retreat
- heavy leg
- high leg
- leg closure (deny wedge/knee line)
- backside flattening (hands push shoulders flat)

Default counters:
- maintain redundant attachment (disengagement must be slow)
- occupy space (remove ankle gaps; deny leg closure)
- backside is a pushing contest: legs must out-push hands

## 9. Failure Signatures → Fix Rules
- **Late defense:** framing after penetration begins → read earlier (distance/angle), apply hip line gate sooner
- **Dead feet:** touch without control → reinsert true barriers/hooks; feet-first contact rules
- **Hand chasing:** arms lead, hips lag → re-square first; hands reinforce after alignment
- **Spin under stable base:** hands-down gate violated → base-break longer before rotation
- **Thin entries:** one step clears attachment → secure ankle/heel handle before climbing
- **Stop-pass-stop:** cycle break without counter → apply Golden Rule immediately

## 10. True Handle Checklist (prevent thin attachment)
A “true handle” is present only if the connection meets these tests:

- **Survival test:** connection survives one full opponent step without breaking.
- **Line test:** you control a *line*, not a surface:
  - ankle/heel line > shin touch > foot touch.
- **Redundancy test:** at least two points of control exist across hands/feet/legs.
- **Orientation test:** you can maintain feet/knees facing while holding the handle.
- **Recenter test:** the handle allows you to keep them in front (prevents angle runaround).

If any test fails, treat it as **thin**:
- reattach to the ankle/heel line,
- build redundancy,
- re-center before climbing.

## 11. Top-6 Situations Playbook (if/then)
Use this as the fast field manual. Gates override everything.

1) **Mobility circle (toe-line circling, low compression)**
   - **Do:** foot pummel + crossover/scoot → re-center
   - **Don’t:** frame early; don’t hand-chase

2) **Shove-to-clear then retreat (backward+push)**
   - **Do:** immediate foot reinsertion + re-center; attach ankle to stop reset
   - **Don’t:** accept disengage; don’t remain unconnected

3) **Kneeling drive (forward+push from knees)**
   - **Do:** frame (high/low as needed) + turn-to-side + shrimp → rebuild → re-run base break
   - **Don’t:** treat kneeling as benign; don’t allow flattening

4) **Backstep reset (backward+pull)**
   - **Do:** follow + maintain true handle; containment hub if entangled
   - **Don’t:** stop-pass-stop; don’t “reset to neutral”

5) **Heavy leg / High leg defence**
   - **Do:** maintain line control; occupy space; upgrade to containment if repeated
   - **Don’t:** climb without a handle; don’t accept ankle gaps

6) **Leg closure / backside flattening**
   - **Do:** deny closure by occupying space; win backside push contest with legs; reinsert barriers
   - **Don’t:** accept flat shoulders; don’t let hands push you flat without leg response
