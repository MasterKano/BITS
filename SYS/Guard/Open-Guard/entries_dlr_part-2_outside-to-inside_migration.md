# Entries (DLR) — Part 2: Outside-to-Inside Migration (No-Gi DLR → Inside Control → Stronger Legs)

## 1. Purpose
No-gi DLR is weakest when you stay “outside” with thin attachments. The upgrade path is **outside-to-inside migration**:
- you start with an outside hook/attachment,
- force a base event (post/step/widen),
- then migrate your control **inside** so the opponent cannot freely backstep/strip.

This module defines the migration triggers, the “don’t get flattened” gates, and the routing outcomes (to stronger leg-entry hubs or closed-guard governance when appropriate).

## 2. Inputs / Preconditions
- You have a DLR hook and at least one **true handle** (hook-only is not enough).
- Opponent is standing (often staggered).
- You can create an off-balance event or can capitalize on one.
- You can keep hip line safe (frames available if pressure collapses).

## 3. Outputs / Success Criteria
- You migrate from outside DLR attachment into **inside control** without losing contact.
- You deny:
  - immediate backstep,
  - pull-away/disengage,
  - pressure collapse during the migration.
- You arrive at a stable downstream system state:
  - inside entanglement/hub selection, or
  - controlled re-entry to a distance connector, or
  - closed-guard transition if two-leg control becomes available (Vol 8 governance).

## 4. Core Model / Engine
**OUTSIDE ATTACHMENT → BASE EVENT → INSIDE MIGRATION → RE-LOCK → ROUTE**

Operational loop:
1) Ensure attachment quality (hook + true handle).
2) Create/read a base event (post/step/widen/weight shift).
3) Move your control inside while keeping a distance governor.
4) Re-lock in an inside-dominant configuration.
5) Route immediately (don’t linger in “half-migrated” state).

## 5. Gates (override rules)

### 5.1 Attachment Quality Gate (migration requires a handle)
If your outside attachments are thin, migration becomes a scramble you lose.
- **Default action:** upgrade to hook + true handle before migration.

### 5.2 Trigger Gate (base event first)
Trying to migrate inside against a stable stance invites backstep.
- **Default action:** force/read post/step/widen, then migrate.

### 5.3 Anti-Backstep Gate (time-critical)
Backstep is the opponent’s simplest denial during migration.
- **Default action:** maintain a **center-line distance governor** (foot placement) and track their stepping foot.

### 5.4 Anti-Pull-Away Gate (lock before chase)
If they withdraw, you must clamp or route.
- **Default action:** clamp/contain if you can; otherwise route to shin-to-shin / 2-on-1 ankle immediately.

### 5.5 Hip Line Safety Gate (no migrating while flattened)
If pressure is collapsing you, migration is suspended.
- **Default action:** frames high/low + turn-to-side + shrimp → rebuild → re-attach.

## 6. Top-6 Situations Playbook
1) **You have outside DLR but feel “slippery”**  
   → **Default:** upgrade to true handle first, then migrate.

2) **Opponent posts hand or takes a recovery step**  
   → **Default:** migrate inside immediately (trigger satisfied).

3) **Opponent starts to backstep as you migrate**  
   → **Default:** center-line foot + follow foot; keep inside migration path.

4) **Opponent squares stance (kills outside angle)**  
   → **Default:** create base event (off-balance); then migrate to inside line.

5) **Opponent pulls away during migration**  
   → **Default:** clamp if possible; if contact breaks, route to distance connectors.

6) **Opponent collapses forward pressure**  
   → **Default:** frames first; re-attach; re-run trigger gate.

## 7. Opponent Reactions → Responses
- **Backstep:** track stepping foot; keep distance governor; finish migration only after you’re attached.
- **Pull-away:** clamp/contain or route to distance systems (no hand chasing).
- **Turn-out/toe rotation:** keep control centered; do not lose inside line; re-lock.
- **Pressure collapse:** frames/angle first; then migrate.

## 8. Failure Signatures → Fix
- **“I migrate and lose everything.”** → attachment quality too low; upgrade handle first.
- **“He backsteps every time I try.”** → you’re migrating without a trigger; force/read base event first + distance governor.
- **“He just walks away.”** → you chased without clamp/route; clamp earlier or route immediately.
- **“I got flattened mid-migration.”** → hip line safety ignored; frames first.

## 9. Trigger Recognition Checklist
Migrate outside-to-inside when 2+ cues are true:
- [ ] hook + true handle are established
- [ ] opponent posts or widens base
- [ ] opponent takes a recovery step / weight shift
- [ ] you can place a center-line distance governor during the transition
- [ ] hip line is safe (no immediate flattening)

## 10. Quality / Capture Checklist
- [ ] migration is done off a trigger (not on stable stance)
- [ ] distance is governed (center-line foot; follow foot on backstep)
- [ ] you do not lose both anchors simultaneously
- [ ] you re-lock into inside-dominant control
- [ ] you can route immediately to a downstream hub/entry family

## 13. Drills and Games

### 13.1 Triggered Migration Only
- **Start:** outside DLR (hook + true handle). Opponent begins stable; then will post/step on cue.
- **Defender wins:** migrate inside only after trigger and hold inside lock 3s.
- **Passer wins:** force migration attempt before trigger (rep loss) or escape/disengage within 5s after trigger.
- **Rules:** any migration before a base event = rep loss.
- **Reset:** 3s hold or escape.
- **Rounds:** 10 reps each, switch.

### 13.2 Backstep During Migration (distance governance)
- **Start:** defender begins migration; opponent’s only defense is immediate backstep.
- **Defender wins:** maintain center-line distance governor + follow foot; complete migration to inside lock within 5s.
- **Passer wins:** complete backstep escape/disengage within 5s.
- **Rules:** if defender freezes (fails to track stepping foot), rep loss.
- **Reset:** lock or escape.
- **Rounds:** 8 reps each, switch.

### 13.3 Pull-Away Branch (clamp vs route)
- **Start:** migration underway; opponent chooses pull-away as defense.
- **Defender wins:** either clamp and stop disengage for 3s, or if contact breaks, route to shin-to-shin/2-on-1 ankle within 5s.
- **Passer wins:** disengage to two steps with no immediate recapture.
- **Rules:** no hand chasing; must choose clamp or route immediately.
- **Reset:** 3s hold, successful route, or escape.
- **Rounds:** 8 reps each, switch.
