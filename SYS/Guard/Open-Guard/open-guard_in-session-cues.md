# Open Guard — In-Session Cues (Operator Cards)

## Decision Ladder (run this first)
~~~
OPEN GUARD LIVE LOOP (10s decision)

START: "What is he doing right now?"

1) SAFETY CHECK (always first)
   if HIP LINE THREATENED (flatten/chest-to-chest incoming)
      -> A1 frame high/low -> turn-to-side -> shrimp/re-square
      -> then go to 2
   else if CENTER LINE LOST (legs off-center; step-around threat)
      -> A2 recover center line (pummel/recovery) -> then go to 2
   else if FACING LOST (hips turned away)
      -> A3 re-square (feet/knees facing) -> then go to 2
   else if CONTACT THINNING (about to lose all anchors)
      -> A4 clamp ONE meaningful anchor; deny two-step -> then go to 2
   else
      -> go to 2

2) PASSER PROFILE (choose module)
   if FORWARD DRIVE / PRESSURE CHAIN STARTING
      -> B1 framing layer; no leg entries under drive
      -> if pressure persists: pressure ladder
      -> then go to 3 (only after cycle-break)
   else if MOBILITY / CIRCLING / OUTSIDE LANE HUNTING
      -> B2 square + center line + barriers; no overreach
      -> then go to 3
   else if CYCLE-BREAK WINDOW (they reset/light moment)
      -> B3 immediate counter/re-attach
      -> then go to 3
   else
      -> go to 3

3) ENTRY PERMISSION (take what is available)
   if ANKLE LINE PRESENTED (gap)
      -> C1 take 2-on-1 ankle NOW
      -> then go to 4
   else if MID-RANGE LANE (shin-to-shin)
      -> C2 connect shin-to-shin (connector)
      -> then go to 4
   else if KNEELING BASE COMPROMISED (post/widen/forced step/posture break)
      -> C3 commit kneeling entry (half-sumi trigger)
      -> then go to 4
   else
      -> run retention movement 1–2 beats (A2/A3) to CREATE a lane
      -> loop back to 3

4) DEFENSE PROFILE OVERRIDES (if they are killing your legs)
   if HEAVY LEG (your leg is dead under weight)
      -> D1 angle out then repummel
      -> loop back to 3
   else if HIGH LEG (legs lifted/cleared high)
      -> D2 protect hip line; recover center line; don't reach
      -> loop back to 3
   else if LEG CLOSURE (no insertion lanes)
      -> D3 create space first; then insert barrier
      -> loop back to 3
   else
      -> go to 5

5) LEG-ENTANGLEMENT ROUTING (only if you land there)
   if TURN-AWAY / RUN begins
      -> E1 choose 50/50 containment; stabilize 3s
   else if KNEE LINE CLEARS FAST / SLIPPING REPEATS
      -> E2 upgrade to double 50 earlier; stabilize 3s
   else if BACKSIDE PUSH/PEEL CONTEST starts
      -> E3 don't overextend; remove peel leverage; stabilize 3s; route (criss-cross)
   else
      -> use hub-selection rules

END STATE CHECK
- If opponent DISENGAGES TO TWO STEPS at any point -> anti-flee reset/re-capture
- After any successful stabilize (3s) -> progress (don't scramble)
~~~

## How to run (10 seconds)
1) In live rounds, ask: **“What is the opponent doing right now?”**  
2) Match to a cue below.  
3) Execute the **Default** (1–2 actions).  
4) Route to the next cue (Entry / Hub / Reset).

Scoring vocabulary:
- **Hip line threatened** = flattening / chest-to-chest incoming
- **Center line lost** = legs no longer between you and them
- **Two-step disengage** = opponent backs out to clear distance, no meaningful contact
- **Stabilize 3s** = hold the position without scrambling

## A) SAFETY CUES (run these first)

### A1 — Hip line threatened (flatten incoming)
**Read:** shoulders nearing mat, crossface/underhook pressure building, chest-to-chest imminent  
**Default:** frame high/low → turn-to-side → shrimp/re-square → rebuild barriers  
**Win:** you’re re-squared, legs back between you and them  
**Route:** `retention_framing_layer_frame-high-frame-low.md` + `application_pressure-passer_defense-ladder.md`

### A2 — Center line lost (legs cleared off center)
**Read:** your legs drifted to one side; they can step around hips  
**Default:** recover center line immediately (pummel/recovery) → then hand-fight  
**Win:** feet/knees between you and them again  
**Route:** `retention_movement_foot-pummeling.md` + `retention_movement_high-leg-recovery.md`

### A3 — Facing lost (hips turned away)
**Read:** your knees/feet no longer facing; you’re being turned/flattened  
**Default:** re-square immediately (feet/knees facing) → rebuild barriers → re-attach  
**Win:** you can see/track their hips with your hips  
**Route:** `retention_orientation_rule_feet-or-knees-facing.md`

### A4 — Contact thinning (about to lose all anchors)
**Read:** grips/legs peeling off; you’re about to be “nothing”  
**Default:** clamp ONE meaningful anchor (ankle line / shin / wrist line) → deny two-step disengage  
**Win:** they must address your anchor before escaping  
**Route:** `SYS/Meta/governance_anti-flee_the-mat.md`

## B) PASSER PROFILE CUES (choose correct module)

### B1 — Pressure chain starting (forward drive)
**Read:** head/shoulders driving in, weight forward, collapse incoming  
**Default:** framing layer first (no leg entries under drive) → turn-to-side → cycle break  
**Win:** pressure stops; you re-square  
**Route:** `retention_framing_layer_frame-high-frame-low.md` + `application_pressure-passer_defense-ladder.md`

### B2 — Mobility passer circling (angle + speed)
**Read:** constant lateral steps, outside lane hunting, low commitment  
**Default:** square + recover center line → don’t overreach → keep barriers between  
**Win:** they can’t get outside your hips cleanly  
**Route:** `application_mobility-passer_defense-loop.md`

### B3 — Cycle-break window appears (they reset)
**Read:** step-back, posture reset, hand re-grip, “light moment”  
**Default:** immediate re-attach (ankle/shin-to-shin) OR immediate off-balance entry  
**Win:** you reconnect before they rebuild posture  
**Route:** `application_cycle-break_to_immediate-counter.md`

## C) ENTRY PERMISSION CUES (when you’re allowed to enter)

### C1 — Ankle line presented (gap appears)
**Read:** ankle/foot available; you can hold it meaningfully  
**Default:** take 2-on-1 ankle immediately (no hesitation)  
**Win:** ankle line controlled; they can’t freely step back  
**Route:** `entries_distance_2-on-1-ankle-system.md`

### C2 — Mid-range lane present (shin-to-shin gap)
**Read:** you can connect shin-to-shin without being smashed  
**Default:** connect shin-to-shin as connector → then route (RDLR/HQ/X etc.)  
**Win:** you’re anchored mid-range, not floating  
**Route:** `entries_distance_shin-to-shin_connector.md`

### C3 — Kneeling base compromised (HALF-SUMI TRIGGER)
**Read (trigger):** post, widen knees, forced step, posture break, alignment turn  
**Default:** commit kneeling entry only when trigger appears; otherwise stay shallow + create it  
**Win:** you enter without getting crushed into pressure  
**Route:** `entries_kneeling_double-leg-entry_half-sumi-trigger.md` + `decision-model_three-laws_kneeling-standing-head.md`

## D) DEFENSE PROFILES (fast fixes)

### D1 — Heavy leg (your leg connection “dies” under weight)
**Read:** hook/shin pinned; legs feel dead; weight line on your structure  
**Default:** angle out (scoot/shrimp/pivot) to make weight miss → repummel  
**Win:** you regain inside position and mobility  
**Route:** `defenses_heavy-leg.md`

### D2 — High leg (legs lifted toward head / cleared high)
**Read:** calves lifted; knees pushed up; step-around threat  
**Default:** protect hip line → recover center line → re-square (don’t reach)  
**Win:** legs back between you and them before they step  
**Route:** `defenses_high-leg.md`

### D3 — Leg closure (no insertion lanes; “door shut”)
**Read:** knees/elbows tight; ankle space filled; cannot insert shin/hook  
**Default:** create space first (angle/frames) → insert barrier immediately  
**Win:** you open a lane and attach without fishing  
**Route:** `defenses_leg-closure_fill-space.md`

---

## E) LEG-ENTANGLEMENT ROUTING (hub governance)

### E1 — Turn-away/run begins from leg exchange
**Read:** hips rotate away; they’re trying to run out  
**Default:** choose containment (50/50) to stop the run → stabilize 3s  
**Win:** they can’t disengage by turning away  
**Route:** `SYS/leglocks/control-hubs/governance_hub-selection_rules.md`

### E2 — Knee-line clears fast / repeated slipping
**Read:** knee line retracts in one action repeatedly  
**Default:** upgrade containment (double 50) earlier  
**Win:** clears slow down; stability improves  
**Route:** `SYS/leglocks/control-hubs/governance_hub-selection_rules.md`

### E3 — Backside pushing contest (legs push out vs hands peel)
**Read:** they peel legs with hands while you’re pushing out to retain  
**Default:** don’t overextend → remove peel leverage → stabilize 3s → route (criss-cross if needed)  
**Win:** peel attempts stop producing disengage  
**Route:** `SYS/Meta/governance_backside_pushing-contest_legs-outpush-hands.md` + `SYS/leglocks/control-hubs/hub_criss-cross_inside-outside_backside-stability.md`

## F) SESSION USE (micro-plans)

### F1 — 3-cue pack (default weekly plan)
Pick one from each:
- **Safety:** A1 or A2
- **Entry:** C1 or C2
- **Leg governance:** E1 or E3

Write it on the mat edge. Run only those three cues for the session.

### F2 — Post-round quick log (10 seconds)
- **Which cue triggered most?**
- **Did I run the default?**
- **Did it stop the opponent (yes/no)?**
If no: open the linked SYS page and update your “Failure signature → Fix” line.
