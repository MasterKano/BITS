# leglocks — systems index (canonical)

## Purpose

This folder is the **single canonical** systems library for leg locks in BITS.

- Canonical means: if a topic already exists in `SYS/leglocks/`, you **update that file** rather than creating duplicates for a new instructional.
- Detail lives in `INS/` (BIO, VN, transcripts). `SYS/` holds the durable, merged “system view.”

## How to use this folder

1. Start with the maps:
   - `./index/ashi-hierarchy.md`
   - `./control-hubs/knee-line-and-wedge-control.md`
2. When adding a new instructional, merge into the *existing* canonical file(s) below.
3. If a topic is truly missing, create a new file in the appropriate bucket (control-hubs / positions-ashi / transitions / submissions).
